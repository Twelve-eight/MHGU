# MHGU v1.4.0 道具箱扩容补丁（V7）

把一个 2,300 格的道具箱扩到 **2,992 格**，预设从 24 组减到 14 组。

## 装之前

- **只支持 v1.4.0**，build `FB08F1D20FD1204FE7070672777F869B`。别的版本会崩。
- **打过补丁的存档，原版游戏读不了**（箱子布局变了）。要回原版，先用备份存档。
- 只在自己的存档副本上试。

## 文件

| 文件 | 用途 |
|---|---|
| `1.4.0.pchtxt` | 主补丁，123 条逐行替换（Atmosphère / yuzu 的 pchtxt 格式） |
| `experimental-v8/1.4.0.pchtxt` | V8 实验分支（容量 getter + 对象布局），**未运行验证** |

## 怎么用

1. 备份存档目录（`system`、`system_backup`、`hunter*.hnt`）。
2. 把 pchtxt 放到模拟器/主机的补丁目录，文件名与 build id 对应。
3. 进游戏，箱子里应该能看到第 2,300 格之后的空间。

## 这套补丁改了什么

- `movw` 立即数：箱子容量 2,300 → 2,992（补丁表里逐条替换指令字，不动其余字节）。
- 预设区布局：24 组 × 170 B → 14 组，腾出的位流空间给新增格子。
- 补丁表共 **123 条**，与镜像逐条核对过，**0 处偏移或取值不符**（`tools/patches` 的核验脚本）。
