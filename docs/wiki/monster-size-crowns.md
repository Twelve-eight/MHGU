# 怪物体型与冠级（Monster size and crowns）

本页说明怪物出现时的体型比例如何抽取，以及三个冠级阈值（S / B / K）对应的数值表。数据全部来自逆向报告 `.tmp/reports-mhgu/re-crown-size.md`。

## 标签说明

- [C]：romfs 字节与主程序代码地址交叉验证。
- [B]：单一字节级来源。
- [I]：推断，未直接观测。
- [X]：来源冲突。
- [U]：未知，不作为事实使用。

## 冠级是什么

游戏中的冠级由一个比例决定，而不是绝对体长。
实际体型 = TrueSize × 抽取比例。存档 0x60CA 处的记录以 `round(比例 × 100)` 保存，常见值为 88 到 125。[C]

TrueSize 的绝对单位（厘米或引擎单位）[U]：本地没有可核对的第三方体长来源。冠级百分比轴不受影响。

## 抽取方法

每次遭遇的比例由两步相乘得到。[C]

1. **任务体型百分比（Size%）**：每个任务的怪物槽位中，`Size` 为 u8 百分比。标准任务多数为 100。
2. **emyure 组抽取**：任务中的 `SizeTbl`（0 到 51）选择一个组。组内每个元素带权重，组内权重和为 100。

计算式：

    比例 = Size% × 组内抽取的 scale

验证方法：对每只怪物，取其全部任务的 (Size, SizeTbl) 组合，计算 [Size × 组最小, Size × 组最大] 的并集。存档中记录的最小值与最大值都应落在该并集内。
- 干净存档（slot1）：41 / 41 通过。[C]
- 脏存档（slot0）：71 / 72 通过。唯一失败项为 野猪王 maxi=154，属于已记录的异常（参见 mon-size-calc.md U4）。[C]

结论：比例 = 任务 Size% × 由 SizeTbl 选出的组中抽取的 scale。[C]

## 强制体型的任务（128 行）[C]

128 个任务槽的 `Size` 不为 100，即任务强制了出现比例。主要包括：

- 激昂 / 超越（Deviant EX / G）任务，q40103 到 q41816。例如 q40115 红盔青熊兽 EX 为 96；q40216 大雪主白兔兽 EX 为 96；q41416 铠裂将军镰蟹 EX 为 115；q40416 紫毒姬 EX 为 110 / 125。
- 特殊任务：q507（Hunt-a-thon: Khezu）中白电龙为 92；q40410 中火龙为 120 / 98；q11103、q11125、q11127、q11232 对应 em76、em60、em65、em22 的强制体型。
- q90122 中火龙为 50，该任务不在 mhgu.db 中，仅有字节级来源。[B]

事件任务 q1011013 到 q1011024 是仅有的 `SizeTbl` 为 50 或 51 的任务。[C]

标准任务的惯例：每只怪物的任务从 `SizeTbl` 2、3、4、5 中选一个，Size 为 100。有 30 只怪物拥有完整的 {2,3,4,5} 组。0 和 1 也会出现。[B]

## 冠级名称与阈值 [I]

每只怪物只有三个有序阈值 S < B < K（S 小于 1，B 大于 1，K 不小于 B）。逆向报告中没有任何来源把三个阈值映射到小金冠、银冠、大金冠。

推断的对应关系为 S = 小金冠，B = 银冠，K = 大金冠。[I] 皇冠（小皇冠、大皇冠）的存在由 medals-guild-card.md 第 90 到 91 行证实，但该页没有给出阈值与皇冠之间的对应。[I]

未确认的细节：

- 阈值是否包含等号（≤ 还是 <），以及大金冠是否要求超过 K 还是落在 K 到 Qmax 之间。[U] 逆向中未找到比较指令位点，需要运行时跟踪。
- 抽取值超出 [Qmin, Qmax] 时是拒绝还是截断。[U] 所有已观测存档记录都在范围内，但规则未被观察到。

## 没有数据行的怪物 [U]

`em_size_scale_data` 中有 54 个全零行（行号 29、33、41、46、69、71 到 111、116 到 119、133、135、136）。这些行对应的怪物没有体型阈值数据。逆向报告列出的家族包括霸龙、崩龙、煌黑龙、岚龙、老山龙、黑龙、骸龙和阁螳螂，但未逐行确认对应关系。[U]

这些怪物有两种可能：从不通过这张表判定冠级，或使用其他路径。存档中也没有这些怪物的体型记录。[U]

## 刷冠建议（由组范围推导）

以下结论仅由上面的 Size% 与组范围推导，不是实测。[I]

- **组 0（SizeTbl 0）** 范围仅为 0.96 到 1.04，任务中很难出现冠级差异。
- **组 3 与 4** 范围最宽（0.88 到 1.25）。若任务 Size 为 100，抽取值达到 K 时需要 1.23 以上，仅落在组尾部。逆向报告未给出组内权重分布，因此达到 K 的概率为 [U]。
- **强制体型任务** 把整个区间按 Size% 平移。例如 Size 为 110 时，组 3/4 的最大值为 110% × 1.25 = 1.375，因此可以越过多数怪物的 K 阈值。但该任务的 Size 是否决定最终冠级，取决于上文未确认的阈值规则。
- 挑选任务时，应优先选择 SizeTbl 为 3 或 4、且任务 Size 高于 100 的任务，以提高越过 K 的可能性。[I] 具体概率需要实测样本。
