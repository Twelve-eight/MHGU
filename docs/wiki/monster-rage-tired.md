# 怪物的愤怒与疲惫（Enrage / Tired）

> 怪物会随着战斗进程进入**愤怒**和**疲惫**两种临时状态。本页汇总两者的触发方式、持续规律、对战斗的实际影响，以及可查证的逐怪数值表。
> 证据分级：**[C]** = romfs 数据文件字节级验证（`arc/enemy/emNNN_00.arc :: emNNN_00_dttune`）｜ **[I]** = 第三方数据库 mhgu.db（MHGenDatabase v2.4.0，未经 romfs 对拍）｜ **[U]** = 结构已定位、数值/语义未验证。

**本页三句话**：
1. 愤怒与疲惫由怪物内部状态机驱动（代码已定位），疲惫的触发蓄积阈值已从游戏数据文件解出并给出 65 只大怪的总表；
2. 怒时怪物攻击与动作速度上升、部分怪肉质变化、陷阱与闪光效力下降；疲时怪物流口水喘气、行动迟缓，此时陷阱/闪光更有效；
3. 愤怒的触发伤害阈值与怒时倍率的精确数值字段**尚未从数据文件解出**（字段结构已定位，标记 [U]），本页不做臆测。

---

## 1. 玩家侧：这两个状态是什么

**愤怒（怒り / Enrage）**：怪物受到足量伤害后触发。表现为怒吼、身体冒蒸汽/红光，之后一段时间内：
- 攻击欲望与攻击力提升、移动与出招速度加快（游戏内可观察 [I]；代码侧存在对应的倍率字段，见 §3）；
- 部分怪物的**肉质会变化**（如轰龙头部斩击吸收 65 → 70、气绝 100 → 130，见 §5）；
- **麻痹陷阱/落穴陷阱/闪光弹的持续时间缩短**（例：轰龙落穴 16s → 怒时 12s）。

**疲惫（疲れ / Tired）**：怪物蓄积足量"减气"值后进入（主要由**锤、狩猎笛的打击、减气弹/减气瓶**等造成，游戏内可观察 [I]）。表现为流口水、喘气、动作明显变慢，期间会**倒地硬直**，之后会去进食恢复 [I]。此状态下：
- **陷阱与闪光持续时间变长**（例：轰龙落穴 16s → 疲时 20s、闪光 20s → 30s）；
- 多数怪在疲时倒地是输出的最佳窗口。

来源：道具效力数值出自仓库镜像表 `docs/mechanics/monsters.md` §6（外部 wiki 镜像）[I]。

## 2. 状态机（代码证据）

怪物状态由 u8 状态槽驱动（实测见下）。`0x10691dc: ldrb r0,[r4,r0]`（r0=0x73E1）读取 **`[this+0x73E1]`**，随后 `0x10691e0: sub r0,r0,#110` + `cmp #4` + `bhi` ⇒ 该字节值 **110..114 的 5 个状态**走 `bl 0xc03d8` 处理（ARM 反汇编实测 [A]）；这组状态对应愤怒相关处理 [B]。疲惫状态的专门判定点未在本次分析中取证 [U]。

| 项 | 地址 | 说明 |
|---|---|---|
| 愤怒进入动作 | `0xD216A4`（`Angry_Start`） | 引用愤怒动作名 |
| 愤怒循环 | `0x106873c`（E10，引用 `angry_Loop`@0x1583f76、`normal_Change`@0x1585338） | 怒↔通常切换处理 |
| 进入愤怒写标志 | `0x1068dd8`（r1=1） | 写 `[this+0xCBF1]`、参数槽 21（`bl 0x6f6e8`） |
| 疲惫处理 | `0x1068dd8`（r1=2）→ `0x1068f28..` | 参数槽 33/34/36（`bl 0x6f6e8`），疲劳时长下限 1 |
| 疲惫切换/循环 | `tired_Change`@0x1585293、`tired_Loop`@0x1585422 | 动作名（rodata 0x1580000 段） |
| 愤怒参数类 | `cAngryParam` 24 B（类注册 0x26ab70）、`rAngryParam` 112 B（0x2709e0，资源串 `angryprm`@0x155db11） | class-inventory 实测 |
| 耐力参数类 | `cEmStaminaData::cStaminaLev`@0x1556955、`StaminaSubRate`@0x1552649、`StaminaTimeVal`@0x1552670、`IkariRate`@0x1552658（cEmDouMouKaData 42 成员块） | 同上 |

来源：`docs/mechanics/monster-code-map.md` §1、`docs/mechanics/monster-classes.md`、`docs/analysis/monsters/mon-class-map.md` §D；分支行为为本页 worker 反汇编实测 [A]。

## 4. 疲惫触发蓄积表（65 只大怪）

字段含义：
- **initial** = 首次触发需要的减气蓄积值；**increase** = 之后每次需要的增量（第 k 次阈值 ≈ initial + (k-1)×increase，参考 db 自洽规则 [I]）；**max** = 蓄积上限。
- **0/0/0 = 完全免疫减气**（无疲惫状态）。
- 来源缩写：`dttune` = romfs `arc/enemy/emNNN_00.arc` 内 `emNNN_00_dttune` Exhaust 记录（模板 `[initial, A, B, durF, increase, max]`，A/B 逐怪可变——多数怪 A=600、B=5，角龙 poison/exhaust B=10；块偏移逐怪浮动，模式定位+与 db 四元组全对上者标 [C]）；`db` = mhgu.db monster_status [I]。

## 5. 愤怒时的肉质变化（可验证样本）

`monster_damage.json`（与 romfs dttune 0x8E 肉质表对拍一致 [C]，见 `docs/reference/formats/dttune.md`）为 16 只怪提供了 `(Enraged)` 愤怒行（75 行）。样本：

| 怪物 | 部位 | 通常 → 怒时 |
|---|---|---|
| 轰龙 | 头 | 斩 65→70、打 55→65、弹 55→60、气绝 100→130 |
| 轰龙 | 颈/背 | 弹吸收 +5（颈 25→30、背 30→35） |
| 天彗龙 | 头 | 元素吸收 25 → 0（怒时火水雷冰全无效化倾向） |

来源：`docs/data/json/monster_damage.json`（`body_part LIKE '%Enraged%'` 75 行）+ `docs/mechanics/monsters.md` §3.5 交叉示例 [I→部分 C]。哪些怪物有怒时肉质：db 内 16 只（轰龙、火龙族、金狮子、碎龙等）。

## 6. 状态与道具的联动（速查）

| 道具 | 通常 | 怒时 | 疲时 |
|---|---|---|---|
| 落穴陷阱（轰龙） | 16s | 12s | 20s |
| 麻痹陷阱（轰龙） | 10s | 8s | 15s |
| 闪光弹（轰龙） | 20s | 20s | 30s |
| 陷阱肉 | 多数兽龙/鸟龙种仅疲时或未发现时有效 | — | 有效 |

规则：怒时陷阱/闪光**缩短**，疲时**延长**；古龙种、二名个体多对陷阱免疫。全怪数值见 `docs/mechanics/monsters.md` §6（外部镜像 [I]）。

## 7. 待补（数据源已明确，后续可解）

1. **愤怒触发阈值/持续秒数/怒时倍率**：dttune 0xE6..0x18A 浮点区 + 20 B 参数记录块（`[f32, u16×2, u32×3]`，与 24 B `cAngryParam` 类的关系 [U]）；下一步 = 反汇编 `0x1068dd8` 的参数槽 21 读取链，把 dttune 字段钉死。
2. 其余 ~20 只怪 Exhaust 的 dttune 级验证：状态块偏移逐怪浮动（0x324/0x35C/0x39C 均有），等 `monster-dttune-index.json`（DtTuneAll 批量）落盘后逐行升级 [C]。
3. 疲惫的"进食恢复"细节（吃什么、恢复多少、有没有 CD）：需动作表（`*_cmdtbl`）或代码侧 tired_Loop 分析。
4. 怒时攻击倍率的玩家侧数字（例如"怒时伤害 ×1.1"之类）：在数据文件给出字段级证据之前，本页**不提供**任何倍率数字。
