## 0. 记号与取数口径

| 记号 | 含义 |
|---|---|
| `db:9` | `MHGU/docs/data/mhgu.db` 的 `items._id`（= romfs `nativeNX/table/itemData.itm` 的记录下标，0..2990） |
| `chS:9` | 官方中文 `nativeNX/chS/table/itemData_chS.gmd`：槽位 **2×id**（道具名）与 **2×id+1**（说明）。规范引用写作 `chS/table/itemData_chS.gmd #18`（名）与 `#19`（说明），本页简写为 `chS:9`。解包副本 `MHGU-private/romfs-extract/gmd/table/itemData_chS.gmd.json`（5982 串 = 2 × 2991） |
| `r1` | `mhgu.db.combining._id`（= romfs `nativeNX/table/itemPreData.itp` 的第 `r-1` 条记录） |
| `2503` `2506` `2615` `2201` `2202` `2959` | MHXX wiki 文本页 `docs/reference/mhxx-wiki/text/<n>.txt` |
| `monsters.md:291` | `docs/mechanics/monsters.md` §6「道具效力」表 |

- 下表每行的**中文名 = `chS` 槽 2×id**、**效果 = `chS` 槽 2×id+1**，不再逐行重复标注；id 列给的是 db 行号，两者一一对应（`str[2*id]`/`str[2*id+1]`，见 `docs/data/romfs-tables.md` §gmd text）。
- **携带上限** = `items.carry_capacity`，与 `.itm` `+0x06 mMaxCount` 同值（抽样 id 1/9/56/71/100 全等 `[X]`）；弹/瓶的官方说明里也写着「最大弹量 N 发 / 最多携带 N 个」，与本表逐条吻合（例外见 §13-5）。
- **买价/卖价** = `items.buy` / `items.sell`；买价即杂货屋售价（回复药 66z 与 `2615` 一致 `[X]`）。
- **稀有度** 只存在于 db（`.itm` 记录里没有该字段 `[I]`）。
- **成功率** = `combining.percentage`，与 `.itp +0x0E`（u8）逐条相等（抽样 10 条 `[B]`）。全表只有 55/65/75/90/95/100 六档。
- 素材名同样是官方 chS（例 `272 药草`、`292 青菇`、`271 蜂蜜`）；括注英文为 db `items.name`，用于与配方表对号。

## 13. 未确认 / 数值缺口

1. **基础数值缺口（最大）**：体力回复量、爆弹伤害、陷阱基础时长、每发弹伤害都不在 `systems.md`、`mhgu.db` 或官方说明里（官方说明只写「少量 / 中量」）。wiki 的 `2984`（植物）/`2985`（消耗品）只有「入手合计 / 用途合计」两列。可用的只有 §10 的**倍率**；要拿绝对值只能解 `main` 里 `cItemBase` 的使用效果分支 `[U]`。
2. **调合数量三源不一致**：`combining.amount_made_*`（Kiranico）、`.itp +0x0F` 那个字节、wiki「个数」列互不相等。例：LV2通常弹 —— db 1 / itp 4 / wiki 2-4；LV1贯穿弹 —— db 4 / itp 3 / wiki 1-3；LV3贯穿弹 —— db 2 / itp 1 / wiki 1-2；增殖铁镐（铁矿石）—— db 3 / itp 6 / wiki 5。**该字节语义未定**，本页数量列一律取 db。
3. **系统文档的旧译名**：`systems.md` §1.2 的两处「大桶爆弾」实为**木桶飞弹 / 木桶飞弹G**（官方 chS 名，见 §6 校对）；其余旧译见 §14。
4. **大生命粉尘（`db:32`，10050z）**：183 条配方里没有它，wiki 调合表也没有对应行 ⇒ 只能靠报酬/支给拿 `[I]`。
5. **染色瓶（`db:218`）上限矛盾**：官方说明写「最多携带 20 个」，但 `.itm mMaxCount` 与 db 都是 **99**；同族的染色球/染色弹也是 99 ⇒ 本页采信 99 `[U]`。
6. **调合失败**：素材是否消耗、是否有失败道具，wiki 未写 `[未确认]`。
7. **调合書加成幅度**：五卷各加多少成功率、覆盖哪些配方，wiki 与 db 都没给 `[未确认]`。
8. **陷阱/闪光时长**：只按怪物与状态给（通常/怒/疲劳），本页只列 8 只样本；全量在 wiki 单怪页，某只怪是否免疫以该页为准 `[U]`。
9. **捕获所需麻醉蓄积**：要几发麻醉球/弹才成立，仓库无来源 `[U]`。
10. **弹药每发参数**：`bowgunShellData.bgsd`（304 B）与 `rapidshotData.raps`（228 B）未解码，弹种威力/连射数 `[U]`。
11. **支给品与自带道具是否共用上限**：EZ 系是独立 id，但「同名道具能否同时带 1+1」只有 id 层面证据 `[I]`，未实机验证。
