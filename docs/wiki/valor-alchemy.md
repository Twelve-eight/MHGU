# 英勇（Valor）与炼金（Alchemy）风格

> 本页回答：英勇风格（任务书与旧资料里的 Brave）和炼金风格怎么玩 —— 槽怎么攒、状态怎么进、
> **每把武器的专属动作是什么**、奇异炼金桶能做出什么、SP 状态被怎么强化。
> 每个结论按行尾标注来源：**[B]** = romfs 官方 chS 文本表逐串读到（GMD 串表，按串号或 label 引用）；
> **[X]** = 两源以上交叉一致；**[I]** = 推断（有证据但未闭环）；**[U]** = 仓库内无证据，本页不给值。
> 官方文本只给定性规则，**槽容量、秒数、消耗速率一类数值全部缺失**，见 §7。

5 行速览：

1. chS 官方名是 **英勇风格**（`style_tatsujin`）与 **炼金风格**（`style_kizuna`），英文版串分别是
   `Valor Style` 与 `Alchemy Style`。仓库旧页写的「勇气（Valor）」是镜像 wiki 的译名，技能文里的槽名也一样：
   官方 chS 写作 **英勇槽**，镜像 wiki 写「勇气槽」[X]（§0）。
2. 英勇的核心是 **收刀持续**：长按 Y 持续收刀，**以消耗体力与耐力为代价抵挡怪物攻击**；
   收刀持续中按攻击键出「容易累积英勇槽的动作」。槽满进入 **英勇状态**，效果持续到槽耗尽 [B]（§1）。
3. 英勇状态按武器换动作：官方操作注记直接把一批动作标成「仅限英勇状态」（大剑强蓄力斩、太刀纵斩/移动斩、
   铳枪英勇炮击与英勇龙击炮、长枪挥盾攻击、盾斧变形斩、重弩蹲下射击与强力冲刺等），逐武器见 §2 [B]。
4. 炼金的核心是 **奇异炼金桶**：摇桶产出 **12 种炼金道具**，官方按「炼金 1/2/3/4/5 次可制造」分五档；
   道具只在本任务内有效，任务结束统一回收 [B]（§3、§4）。
5. SP 侧：炼金能把 SP 状态强化到 **SP 状态Ⅰ-Ⅳ**（给自己与同区域同伴），且**只有炼金**能装 **3 个 SP 狩技**，
   其他风格最多 1 个；SP 狩技的槽消耗比普通狩技略多 [B]（§3.4、§3.5）。

### 1.2 收刀持续（通用，按武器分三种帮助文）

`HN_WeaponControlsMsg_chS` 里英勇风格的通用帮助有 **3 条**，按武器类型替换最后一句：

| 串 | 适用 | 官方原文（去掉颜色标记） |
|---|---|---|
| `WC_Bra_skillnote_1` | 近战 | 「【收刀】长按Y键，能持续收刀动作。收刀持续中，以消耗体力和耐力为代价，可抵挡来自怪物的攻击。收刀持续中通过按下各攻击键来使出容易累积英勇槽的动作。【英勇状态】累积完英勇槽后，会变成英勇状态，在英勇状态中一定期间内，能使出专属技能」 |
| `WC_Bra_skillnote_2` | 弩炮 | 同上，但「收刀持续中通过按下**装填键**来使出**英勇装填**」 |
| `WC_Bra_skillnote_3` | 弓 | 同上，但「收刀持续中通过按下**发射键**来使出容易累积英勇槽的动作」 |

⇒ 收刀持续的代价是 **体力 + 耐力**，收益是「能抵挡怪物攻击」并接出攒槽动作 [B]；
**抵挡的判定范围、伤害是否穿透、消耗速率** 官方文本都没写 [U]（§7 #2）。

> 「适用」列是按帮助文里出现的按键（攻击键 / 装填键 / 发射键）归类，属 [I]：
> 哪把武器取哪一条要读该武器的命令表，本仓库尚未逐武器对齐（§7 #12）。

### 1.3 英勇槽怎么涨、怎么满

| 规则 | 原文/依据 |
|---|---|
| 攻击怪物累积 | 「可以通过不断攻击怪物……累积英勇槽」`HTM_tatuzinStyle_P1` |
| 收刀持续化解怪物攻击也累积 | 同上 [B] |
| 收刀取消攻击累积 | 同上 [B] |
| 槽满 → 进入英勇状态 | 「累积完英勇槽后，会变成英勇状态」`WC_Bra_skillnote_1`；「累积专用的能量槽之后，英勇风格会进入威力强大的英勇状态」`HTM_tatuzinStyle_P1` |
| 技能加成 | 无念/明镜止水：更容易积攒狩技槽、**英勇槽**和炼金槽（`skillTypeData` #217 / `skillData` #401）；忍耐/虎视眈眈：**受到怪物伤害时**也能积攒三槽（#219 / #403）[B] |
| SP 状态Ⅰ | 进入 SP 状态后更快累积英勇槽、更容易进入英勇状态（`CommonMsg` #193 / `HTM_tatuzinStyle_P3`）[B] |
| 支援行动给的是 SP 状态 | 猎喵/随从在使用第 1 个固有支援行动或特定支援行动时让周围同伴进入 SP 状态（`HTM_HuntArtSP_P5/P6`）[B] |

- 三槽是**并列的三个计数器**，不是同一个槽：技能文每次都写「狩技槽、英勇槽和炼金槽」三连 [B]。
- **槽容量、每击增量、英勇状态的秒数、SP 加成的百分比全部没有** [U]（§7 #1）。
