# 农场·交易·食堂（村庄循环）

> **一句话**：MHGU 没有玩家自己耕种的农场——村庄侧的「生产」是**交易窗口**的「增加道具」（派随从艾露猫去 4 个交易地点采购），货币是**龙历院点数**（存档 `char_off 10251`）。
> **食堂**（贝鲁纳村推车摊 / 艾露猫小酒馆 / 集会所餐桌）= 2 个「食材」组成的**餐品** + 一层**酱汁**，决定固定食事技能，第 2/3 槽常由**每日抽奖**填充；可用金钱或龙历院点数支付，也可用**餐券 / 高级餐券**免费用餐。
> 本文每条数字都带来源：`chS/table/*.gmd #序号`（官方中文文本）、`mhgu.db <表> #行号`、`wiki <页号>`（`docs/reference/mhxx-wiki/text/<页>.txt`）、`systems.md §x`、`DEVELOP.md:行`。未证实的一律标 `[U]`，由结构反推的标 `[推断]`。

## 1. 先定性：MHGU 的「农场」是什么

| 说法 | 结论 | 证据 |
|---|---|---|
| 有玩家自己种植/收获的农场（P3/MH4 式） | **没有**。摩加村的农场是 NPC 的，玩家只接他的委托 | `TradeNPC` 无农场入口；`npc_327_td_chS #1`：「老夫在海边一个叫做"摩加村"的地方经营农场……大家都称呼老夫农场主」 |
| 玩家的「采集生产」入口 | **交易窗口 → 增加道具**：派随从艾露猫去交易地点采购 | `LbHelp #247`（`TradeShop_002`）「委托随从艾露猫进行交易并支付其龙历院点数，在玩家进行任务时道具的数量就会增加」 |

## 2. 交易窗口（剑喵丸）

### 2.1 三个功能

| 菜单 | 做什么 | 代价 | 来源 |
|---|---|---|---|
| **增加道具** | 派随从艾露猫去交易地点，任务回来后道具数量增加 | 龙历院点数（按订购道具计价，见 §2.4） | `TradeShop #1/#35`、`LbHelp #250`（`ItemIncrease_001`） |
| **兑换点数**（UI 名） | 用龙历院点数买交易品 / 特别物品 / 限定物品 / 特殊许可任务券 | 龙历院点数 | `TradeShop #2/#64`、`LbHelp #256/#258/#259` |
| **缴纳委托** | 缴纳村民要的道具，领取报酬（设施升级、食材、装备制作法） | 指定道具 ×N | `TradeShop #3/#84`、`LbHelp #260`（`DeliveryQuest_001`） |

补充事实：
- 三个功能在**自己家 / 房间 / 准备区域的管家**处也能全部使用 `LbHelp #262`（`RoomService_001`）。
- 缴纳委托「没有委托时则不会显示」`LbHelp #249`（`TradeShop_004`）。

### 2.2 「增加道具」的执行规则

| 项 | 规则 | 来源 |
|---|---|---|
| 派谁去 | 必须**已雇用**的随从艾露猫；每辆手推车 1 只 | `TradeShop #138`、`#9/#17` |
| 手推车数量 | 随剧情增加：**1 → 2 → 3** 辆（＝可同时派 1/2/3 只） | `TradeNPC #18/#21` |
| 可订购的道具 | **必须是你已经获得过的道具**；委托时**不消耗**现有道具 | `TradeNPC #46`、`TradeShop #139` |
| 委托次数 | 可选多次；次数越多带回来的越多 | `TradeNPC #48` |
| 期待值 | 由**要增加的道具价值 + 负责随从的 LV + 随从的情绪**决定；期待值越高越容易增加，且**可能出现稀有道具** | `LbHelp #252`（`ItemIncrease_003`） |
| 小费 | 提供「作为小费的道具」可**提升交易效率**；官方指名的就是**商人橡子** | `TradeShop #57`、`TradeNPC #12`、`LbHelp #253`（`Chip_001`「商人橡子……能提高交易的期待度」）、`itemData #5261` |
| 取消 | 停止交易会**返还部分点数**（提示「将会返还 %d 点点数」） | `TradeShop #41` |
| 收取 | 任务回来后收取；可**进道具袋 / 送道具箱 / 直接卖掉** | `LbHelp #251`（`ItemIncrease_002`）、`TradeShop #38-40` |
| 点数不足 | 直接拦下（持有点数不足） | `TradeShop #45/#56` |

**商人橡子**（官方名，`itemData #5260`）＝ `items` 表 id **2630**（英文名 `Lagniapple`，稀有度 4，售价 100z）`db items #2630`。入手：猎喵任务报酬、探索途中 `TradeNPC #54`。

## 6. 道具箱

### 6.1 容量公式（逆向结论）

游戏内道具箱容量不是固定值，而是由**扩展位**算出来的：

```
容量 = 1000 + 300 × popcount(flags & 7) + 200 × bits      # 上限 2300
```

| 项 | 值 | 证据 |
|---|---|---|
| 公式 | `1000 + 300*popcount(flags&7) + 200*bits` | `patches/item-box-v7-plugin-spec.md:216`（原文逐字含 `flags & 7` 与 `200*bits`） |
| 容量 getter | `0x198F04`（表 23 行「capacity getter: short-circuit the obfuscated …」） | `patches/item-box-v7-plugin-spec.md:162` |
| 30 份内联拷贝 | 起点 **`0x198E74`**（表 25 行「inline capacity (first of 30)」，区间 25-54 行共 30 处），不在 getter 内 | `patches/item-box-v7-plugin-spec.md:164`、`:215-216`、`:444` |
| 上限 | **2300 格**（`0x8FC`） | 代码常量 5 处 `movw #0x8fc`（写/读/清零/正扫/反扫）`DEVELOP.md:60` |
| 扩展层 | 3 位（`flags & 7`）× 300 = 最多 +900 | 与 `Reinf` 的**道具箱扩展【序】【匠】【极】三档**一一对应 `[推断]` |
| 另 2 位 | 每位置 200，共 +400 | 对应哪种解锁 `[U]` |
| 1000 | 初始 1000 格 | 公式常量 |

**扩展途径**：龙识船研究室 → **扩展研究室** → 研究委托 `Labo #2/#5`，费用 = **龙历院点数 + 素材**（`Labo #54-58`「龙历院点数或素材不足」）。三档名称见 `Reinf #0/#2/#4`：

| 档 | 文本 | 说明 |
|---|---|---|
| 【序】 | 道具箱扩展【序】 | 「可以扩展道具箱或随从看板可收纳道具或装备的最大量」 |
| 【匠】 | 道具箱扩展【匠】 | 同上 |
| 【极】 | 道具箱扩展【极】 | 同上 |

> 注意 `Reinf` 的原文是「扩展**道具箱或随从看板**」——扩容同时作用在随从看板上；`DEVELOP.md:490` 给出随从侧道具类型表声明容量 **160**（`mItemType[160]`）。两者关系 `[U]`。

### 6.4 实用提示（都有出处）

1. **出发前在箱子里调合**：箱子直接有「在道具箱内调和 / 从列表中调和」，不必把素材塞满口袋（`Box #13/#14`）。
2. **用道具个人组合省装配时间**：登记好几套（如"狩猎/采集/古龙"），替换时一次到位；缺料会提示缺哪些（`Box #72-92`）。
3. **箱子放在哪都能用**：交易窗口、猛喵队、道具补给队都能在自己家 / 房间 / 准备区域的管家处操作（`LbHelp #262/#309`）。
4. **满箱优先清"可卖给点数/可再生产"的东西**：交易窗口的落空产物（石子/蜘蛛巢穴/虫的死骸/空心骨）都是可批量再生的低价物（§2.4）。
5. **别指望"全收集"**：2300 格 < 2940 种，必须做取舍（`DEVELOP.md:77`）。
6. **点数兑换的产物直接进箱子**：交易品兑换后「将会送往道具箱」，箱子满会直接失败（`TradeShop #66/#103`）——兑换前先腾位置。
7. **猛喵队/万能烧烤的报酬也能送箱**：收取时可选「送往道具箱」，同样受满箱限制（`LbHelp #307`、`Kitchen #101`）。
