# 动作值（Motion Values）

玩家每次攻击的**威力系数**（俗称"动作值"）存放在 romfs 的 per-weapon 命中数据资源里。本页给出
该资源的格式、文件位置，并完整解码**大剑（GS）**与**太刀（LS）**两武器的全部记录。

> 标记：`[C]` = 已从 romfs 二进制解出并可复核；`[U]` = 仓库内无官方逐招名/字段语义未闭环。

## 0. 数据位置与格式

| 项 | 值 | 来源 |
|---|---|---|
| 所在容器 | `nativeNX/arc/player/quest/wNN.arc`（每武器一个，`w00..w15`，w15≈猎猫） | `[C]` ARC 目录枚举 |
| 资源条目 | `player\hit\pl_weNN_hitdata`（type hash `0x4E2EF008`，zlib 压缩） | `[C]` w00.arc 条目表 |
| 命中体积 | `player\hit\pl_weNN_hitsize`（`HTS\0`，球体/胶囊组） | `[C]` |
| 武器参数 | `player\param\pl_wNN`（rFreeUseParam，`0x496F8F22`） | `[C]` |
| 动作流程表 | `nativeNX/table/weaponProcessWNN.wpd`（0x20B 记录：取消/派生顺序，**非**动作值） | `[C]` |
| **武器号映射** | `w00`=大剑、`w07`=太刀（见下） | `[C]` chS 名验证 |

`wNN` ↔ 武器名按 `table/weaponNNMsgData_chS.gmd` 的首个武器串定：`weapon00` #6「贝鲁纳大剑」⇒ w00=大剑；
`weapon07` #6「贝鲁纳马刀（太刀）」⇒ w07=太刀。

### 0.1 `pl_weNN_hitdata` 文件头（16 B）

```
+0x00  u32  magic      "HDP\0"  (0x00445048)
+0x04  u32  version    0x20160209
+0x08  u32  count      记录条数  (w00=61, w07=85)
+0x0C  u32  0
+0x10  record[count]  每条 56 B
```
文件总长 = `16 + count*56`（w00 = 16+61×56 = **3432 B**；w07 = 16+85×56 = **4776 B**）。`[C]`

### 0.2 命中记录（56 B）

字段由 main 内的拷贝函数 `0x168e98`（把记录逐项搬进运行时命中对象）确定。以下 offset 为记录内偏移。

| offset | 类型 | 运行时槽 | 语义 |
|---|---|---|---|
| +0x00 | s16 | →f32 | 方向/角度参数 A `[I]` |
| +0x02 | s16 | →f32 | 方向/角度参数 B `[I]` |
| **+0x04** | **u16** | **+0x38** | **威力 / 动作值**（本表"动作值"列） `[C]` |
| +0x06 | u8 | +0x3A | 命中类型（0→运行时置 1；斩切系多为 1） `[C]` |
| +0x08 | u16 | +0x36 | 参数 `[U]` |
| +0x0A | u8 | +0x3B | 参数 `[U]` |
| +0x0B | u8 | +0x3C | 参数 `[U]` |
| +0x0C | u32 | +0x40 | 参数（常 0x3F800000=1.0f 附近） `[I]` |
| +0x10 | u32 | +0x48 | 参数 `[U]` |
| +0x14 | u8 | — | 参数（0x28/0x1E 等） `[U]` |
| +0x18 | u8 | +0x50 | hitsize 相关 `[I]` |
| +0x19 | u8 | — | **hitsize 组号**（指向 `pl_weNN_hitsize` 内 8 B 项）`[C]` |
| +0x1A | u16 | +0x52 | 参数 `[U]` |
| +0x1C | u8 | +0x55 | 参数 `[U]` |
| +0x1D | s8 | +0x56 (>0 时) | 参数 `[U]` |
| +0x1E | u8 | →f32 @+0x64 | 参数（0xFF→写 −100.0） `[I]` |
| +0x1F | u8 | →f32 | 参数 `[U]` |
| +0x20 | u8 | +0x6C | 参数 `[U]` |
| +0x21 | u8 | +0x57 | 参数 `[U]` |
| +0x22 | u8 | +0x58 | 参数 `[U]` |
| +0x23 | u8 | +0x59 | 参数 `[U]` |
| +0x26 | u16 | +0x9C | 参数 `[U]` |
| +0x28 | u32 | +0x98 | 参数（条件写） `[U]` |
| +0x2C | u8 | +0x9E | 等级 `[I]` |
| +0x2E | u16 | +0xA6 | 参数 `[U]` |
| +0x30 | u32 | — | **复读 +0x04 威力**（冗余镜像） `[C]` |
| +0x34 | u16 | — | 积蓄/参数（96/200/280 等） `[U]` |
| +0x36 | u16 | — | 常 0x4B=75 `[C]` |

**说明**：元素伤害倍率、气绝(KO)、减气、打击/切断细分类型不在这张表直接给出逐字名 ——
这些由记录里多个 u8/u16 共同决定，且实际伤害公式还会叠加武器面板/会心/肉质。
本页只把**已证字段**标 `[C]`；其余 offset 给出但语义标 `[U]`，避免照外部 wiki 脑补。

### 0.3 类与注册

- 资源类 `rPlayerManyAttacks`（type hash `0x18A9225C`）：对象体 0x78 B，`+0x64`=条数、`+0x6C`=记录基址、
  `+0x74`=u32 指针表；`get`（`0x271df0`）按索引返回 `base + idx*4`。
- 资源注册表（`.tmp/mhgu/inventory/resource-registry.txt`）首块 = `rHitSize` + 10×`rPlayerManyAttacks` + 3×`rFreeUseParam`。
- 每个 `pl_weNN_hitdata` 由 `player\param\pl_wNN`（rFreeUseParam）同 arc 一起加载。

## 4. 扩展到其余 12 武器

1. 用 `tools/mhgu/arc.mjs` 解 `nativeNX/arc/player/quest/wNN.arc` 的 `hit` 条目：
   ```
   node tools/mhgu/arc.mjs extract "<romfs>/arc/player/quest/wNN.arc" "<out>" "hit"
   ```
   得 `player/hit/pl_weNN_hitdata.4e2ef008` 与 `pl_weNN_hitsize.5653c1b0`。
2. 武器号 ↔ 武器名：读 `table/weaponNNMsgData_chS.gmd` 首个武器串（`tools/mhgu/gmd.mjs`）。
   已证 `w00`=大剑、`w07`=太刀；其余 `wNN` 依 chS 名逐一定（w15 疑为猎猫）。
3. 解记录：每条 56 B，`+0x04` u16 = 动作值，`+0x06` u8 = 命中类型，`+0x19` = hitsize 组号。
4. 招名：狩技名取 `hunterArtsData_chS.gmd`；普通招无官方逐招名，按社区名标 `[U]`。
