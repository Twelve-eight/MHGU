# 任务与星级推进（MHGU / MHXX）

> **本页能查到什么**
> 1. 村任务 ★1–★10、集会所下位/上位 ★1–★7、集会所 G★1–G★4 的**全部关键任务与紧急任务**，逐条给出目标、地图、时限、报酬金、契约金、HRP、出现条件与数据来源行号。
> 2. 关键任务与紧急任务如何互相咬合、怎样才会开放下一星（含 5 个例外：委托链任务、同星级前置链、HR 门槛、狞猛化计数、HR 解放）。
> 3. 每一行的数字都可用 `mhgu.db` 的 `quests._id` 复查；任务的"关键/紧急"归属与出现条件来自 `docs/mechanics/quests.md`。

**一句话结论**：一个星级里，**关键任务全清 → 出现本星级入口紧急 → 完成紧急 → 下一星开放**；`紧急` 挂在"被开放的那一星"名下，不是上一星。

## 1. 怎么读本页

| 项 | 说明 |
|---|---|
| 任务 | 中文名 / 英文原名。任务中文名沿用 `docs/mechanics/quests.md` 的 wiki 译名（已把残留假名改成汉字），英文名与 `mhgu.db.quests.name` 逐字一致。**怪物中文名另见 §1.1（有官方简中来源）** |
| 目标 | `mhgu.db.quests.goal` 的中文转写；「场上：」后的怪物来自 `monster_to_quest`，标 `乱入` 者 `unstable=1`。素材名用官方简中（`chS/table/itemData_chS.gmd` 的槽位 `2*item_id` 取名、`2*item_id+1` 取说明），例：Comet Rock 赫星石 #4206、Burned Husk 灼热甲壳 #3408 |
| 地图 | `mhgu.db.locations.name_ja`（游戏自身的地图名）；「(夜)」= 该地图夜间版本（id +100） |
| 时限 | 分钟，`quests.time_limit` |
| 报酬金 / 契约金 | z（zenni），`quests.reward` / `quests.fee` |
| HRP | 任务结算的猎人点数，`quests.hrp` |
| 来源 | `q<id>` = `mhgu.db` → `quests` 表该 `_id` 行；`W村★N` / `W集★N` / `WG★N` = `docs/mechanics/quests.md` 同名小节（关键/紧急归属 + 出现条件 + 委托链） |

**证据等级**（全页统一）：

- 时限：`docs/data/romfs-tables.md` §2 记录已用 400 个任务的 `questData_<id>.ext` 与 `quests.time_limit` 对拍 **400/400 一致**（含 37 条非 50 分钟任务），故时限为 **[C] 已交叉验证**。
- 报酬金 / 契约金 / HRP：只有 `mhgu.db`（MHGenDatabase v2.4.0）一个来源，未与 romfs 的 `questData` 数值字段逐条对拍 → **[I]**（数值可信但未二次验证）。
- 关键/紧急归属、出现条件：`docs/mechanics/quests.md` 转述的 wiki 关键任务页 → **[W]**。
- **中文任务名没有官方来源**：romfs 的 `chS` / `chT` 语言树里**没有 `quest/` 目录**（只有 `table/`、`arc/`、`GUI/`），本地包不存在普通任务的中文文本；`chS/table/` 里与任务相关的只有界面串（`QuestMsg`/`QuestBox`/`QuestDialog`）和**配信任务**用的 `guestQuestData`。所以本页的中文任务名一律是 wiki 译名，不是官方译名。
- **但怪物名有官方简中**：`chS/table/MonsterDemo_chS.gmd` 提供 96 条带 label 的官方怪物名（含二名全名），本页目标列按它校正，见 §1.1。
- 地图名按游戏官方日文名转写为简体（古代林、森丘、雪山……）。`chS/table/MapName_chS.gmd` 在 385/385 全量重抽后仍只有**两条占位串**（一条占位标签 + 一条模板串），没有任何中文地图名，所以中文地图名只能转写。

## 2. 推进规则（可直接照做）

```
初始：村★1 / 集★1 的"初始任务"直接可见
对每个星级 N：
    key(N) 全部 clear        → urgent(N+1) 出现
    urgent(N) clear          → 星级 N 正式开放（按它的名义挂紧急）
```

三条容易踩的例外：

1. **紧急挂着"新星级"名字**：村★2「跳跃的不法者」出现条件是"村★1 关键任务全部完成"，但它是 ★2 的入口。集会所同理。
2. **同星级内还有前置链**：村★3/★7/★9 与集★7、G★4 的关键任务里有"先做完 A+B 才出现 C"的链，甚至要求"与某村长/看板娘对话"。表中"出现条件"列已写明。
3. **非任务门槛**：HR、村贡献度、狞猛化任务完成数、大型怪物狩猎总数。见 §6。

> `urgent` 的另一层含义：`quests.json` 里同一条任务可能出现两次（例如村★3「波乱的萌芽」q308/q309、村★10「恐惧吧，红色灾厄彗星」q1005/q1053）。这是第三方任务表把"同一任务的两种编成"重复登记，**星级里只算一条**。

**条数对账**：`quests.json` 里 `key`+`urgent` 共 **148 条**（村 75 / 集 73）；本页按 wiki 关键任务表列出 **151 行**（村 78 / 集 73）。
差额 +3 的构成：村★5 三条四天王任务（JSON 标 `pre-req`）**+3**、村★6「宿命的四天王」（JSON 标 `normal`）**+1**、「波乱的萌芽」重复登记（q308/q309 算一条）**−1**。

## 7. 常见坑

1. **同名任务跨池**：「Stop the Wheel」有 3 条（村★6 q620 / 集★3 q10334 / 集★7 q10701），只有村★6 与集★7 是关键；「The Desert Gourmand」「The New Tenant」「Tackling the Tetsucabra」「Snow with Occasional Lagombi」等在上位星级还有同名的高星重制版（星级不同即不同任务，本表按星级分列）。
2. **★3「波乱的萌芽」重复登记**：q308 与 q309 同名同目标（交纳深渊菇×8），q309 才带 3 只乱入（跳狗龙王/鬼蛙/斩龙）。星级里只算一条。
3. **★5 三条四天王任务是"委托→任务"反向依赖**：只写任务完成位而不推进委托，NPC 不会再给后续；反之委托完成了任务也不会出现。
4. **村★10 的两条同名天彗龙任务**：q1005（50 分钟，讨伐）是紧急；q1053（35 分钟，讨伐或击退）是另一条编成，报酬完全一样。
5. **`Advanced:` = 高难度**：村★10 的 16 条高难度、集会所个别追加任务都用这个前缀，名字和主任务几乎一样，容易走错柜台。
