# 怪物状态异常（阈值、持续时间与陷阱反应）

> 本页回答：这只怪要打多少异常值才会中毒/麻痹/睡着？异常持续多久？陷阱和闪光对它有没有用？
> 数值来源全部标注在行尾：**[C] = romfs 官方数据**（`arc/enemy/emNNN_*.arc` 内 `*_dttune` 状态区，本站逐怪定位并与 `mhgu.db` 对拍），**[I] = 机读库 mhgu.db（MHGenDatabase v2.4.0）**，romfs 侧数据待补。

3 行速览：
1. 每种异常有「初始阈值 → 每次递增 → 上限」三段数值（表内写作 `初始/递增/上限`），第一次累积到 `初始` 就触发，之后每次触发阈值上升 `递增`，最高到 `上限`。
2. 持续时间只有毒/眠/麻/晕四类有（表内 `Xs`）；骑乘/减气/跳跃/爆破是瞬时判定，没有时长概念。
3. 古龙与部分特殊怪不吃陷阱/闪光（另见来源列），表中 `无效` = 该状态完全免疫，连累积值都不存在。

## 字段含义（读表必读）

| 字段 | 含义 |
|---|---|
| 初始（initial） | 首次触发需要的异常累积值。武器异常值 × 动作值换算后累加 |
| 递增（increase） | 每成功触发一次后，下一次阈值的增量 |
| 上限（max） | 阈值封顶值（触发次数 ≈ 1 + (max-初始)/递增） |
| 时长（duration） | 状态生效秒数（毒/眠/麻/晕），按 60 帧/秒换算自 romfs 帧值 |
| 无效 | romfs 中该行不存在（免疫行省略），或 db 记 0 —— 该怪对此状态免疫 |

递增与上限的规则（来源：dttune 记录 + db 语义对拍 [C]）：状态每次被触发后，下一次的触发阈值 = 上一次阈值 + 递增，最多累积到上限。例：雌火龙毒 `180/100/580` → 第 1 次毒需 180 累积，第 2 次 280，第 3 次 380，第 4 次 480，第 5 次起 580 封顶。
