# 怪物部位与体力（HP / 部位破坏 / 断尾 / 捕获）

> **三行摘要**
> - 一只怪的实际体力 = **基础 HP × 任务 HP 倍率**：基础 HP 存在怪物自己的 `dttune` 文件里（romfs 字节，已与第三方库逐字节互证），任务倍率在任务数据里只存一个**表号**，由游戏再查隐藏的难度表。
> - 部位破坏 / 断尾按**部位**累积伤害，与本体 HP 是两套计数；尾部只有**斩系**伤害才累积（打击/弹药不断尾）。
> - 捕获窗口约在 HP **35% 以下**（主力常量 0.35/0.65 已在主程序定位），表现为怪物**跛行回巢**；陷阱 + 捕获玉只在任务目标是「狩猎」时才算完成目标。

状态标记：`[C]` = romfs 字节与仓库既有数据双重验证；`[B]` = 直接读到 romfs/main 字节（结构确认）；`[I]` = 推断或仅第三方库（mhgu.db = MHGenDatabase v2.4.0）；`[U]` = 未核实。

---

## 1. 基础 HP：数据在哪、怎么读

每只怪的资源包 `romfs/nativeNX/arc/enemy/emNNN_00.arc` 里有 `enemy\dt_tune\emNNN_00_dttune`（zlib 压缩，ARC 容器）。解码格式见 `docs/reference/formats/dttune.md`：

| 字段 | 位置 | 验证 |
|---|---|---|
| 基础 HP | dttune `0x38` u32（**唯一定长字段**） | em001 雌火龙 4500 / em002 火龙 4200 / em013 黑龙 9000，与 `mhgu.db monsters.base_hp` 逐字节一致 [C] |
| 肉质表（9 列 × 8 部位） | dttune 内偏移**逐怪浮动**（实测 0x8E、0x8F…） | 雌火龙/火龙/黑龙/斩龙均与 `mhgu.db monster_damage` 一致（各怪实测定位后对拍）[C] |
| 状态阈值（毒/眠/麻/气绝/减气/骑乘/跳跃/爆破） | dttune 内偏移**逐怪浮动**（0x324/0x35C…，个别怪缺失） | 与 `mhgu.db monster_status` 一致（已定位怪）[C] |

注意：dttune 的头部长度**逐怪有差异**（em001 头部 0x0E 字节 `37 0c …`，em080 为 `43 0e …`），肉质/状态表偏移必须**逐怪定位后才能引用**；全怪物逐怪偏移将由 `docs/data/json/monster-dttune-index.json`（DtTuneAll 批处理）发布 [B]。

## 2. 任务 HP 倍率：任务里存的是表号

任务文件 `loc/quest/questData/questData_<7位id>.ext`（记录格式见 `docs/data/romfs-tables.md` §2）里每个目标怪物带一个 13 字节槽（记录偏移 0x05C 起）：

| 偏移 | 字段 | 语义 |
|---|---|---|
| +0 | Id u16 | em 编号 |
| +5 | HealthTbl u8 | **HP 难度表号** |
| +6 | AtkTbl u8 | 攻击表号 |
| +7 | OtherTbl u8 | 其它表号 |
| +9 | Size u16 | 个体大小（% 基准 100） |
| +0xC | StaminaTbl u8 | 疲劳参数号 |

本次用自写脚本（`.tmp/mhgu-scratch/quest-decode.mjs`）解码全部 1849 个 .ext：287 个 (怪物， 敌等级) 组合，表号为 0..135 的整数索引 [B]。

### 2.1 难度表本体（em_nando_tbl）

`loc/arc/resident.arc :: enemy\resident\em_nando_tbl`（4528 B = magic `NAN\0` + 141 × 32 B 记录）[B]。每行 = `{f32 A, f32 B, f32×6 修正}`，A 从 0.1 线性升到 6.5，B 从 0.5 升到 21.0。任务里的 `HealthTbl` 索引直接指向该表行：

| 索引→A（=HP 倍率） | 例 |
|---|---|
| 13 → 0.49 | 村★4 雌火龙（q409） |
| 19 → 0.67 | 集★2 雌火龙（q10219） |
| 49 → 1.57 | G 级雌火龙低端 |
| 60 → 1.90 | 老山龙斗技？ |
| 85 → 2.75 / 102 → 3.60 | G 级高端 / EX 级 |
| 30 → 1.00 | 老山龙村级（q90016） |

**换算**：实际 HP ≈ 基础 HP × A。量级全部落在合理域（G 级雌火龙 4500×1.57–3.60 = 7065–16200），但绝对值尚未实机校验 → **公式 [I]**，表本体位置与结构 [B]。

玩家侧结论（不依赖精确数值）：
1. **同一只怪，村★4 → 集★2 → G 级的 HP 倍率单调上升**，G 级约是村★4 的 3–6 倍 [I]。
2. 任务文本与报酬表**完全看不出** HP 差异，同一星级内的怪也可能用不同表号 [B]。
3. 连战任务（双目标）每只怪独立取各自槽位的表号 [B]。

## 3. 部位破坏与断尾

### 3.1 机制

- 每个可破坏部位有**独立的部位 HP**，与本体 HP 分开累计；打空即触发破坏（部位肉质变化 + 掉落素材 + 尾部可断）。`mhgu.db` 与 dttune 都**不含**部位 HP 数值 [U]。
- 断尾条件：**斩系物理伤害**累积到尾部阈值；打击、弹药、属性伤害不参与累积 [I]（系列通用规则，本作数值未解码）。
- 部位资源包里有 `enemy\dt_base\*_dtbparts`（magic `DTP`）：已辨认出记录流 `{u32 数值, u32 部位id(100+), 位域}`（雌火龙：5097@101、2185@102、3641@103、1820@104…）与尾部 {u16 3005/3006, 0xFF 标记}、f32 尾参 550.0 [B]。**数值语义未定**（量级像「部位耐久 × 某系数」或「部位状态机参数」），不能当部位 HP 表引用 [U]。
- dttune `0xE6..0x18A` 的 f32 串（500/6000/1500/…/2500/5000，怒时类数值对）与 db 无对应，格式文档标 [U]；其中含怒时失衡/眩晕调参的可能。

### 3.2 玩家怎么知道破坏进度

- 部位外观变化（角断/壳裂/尾断）即破坏完成，**游戏不给进度条**。
- 狩猎笔记（HN_MonsterListMsg_chS）的弱点提示不含部位 HP。
- 需要精确「破坏耐久表」请看 `待补` §6。

## 4. 捕获：阈值与条件

### 4.1 阈值证据

- 主程序 `.text` 内嵌常量对 **f32 0.35 / 0.65**（vaddr 0xF513A0/0xF513A4，紧跟函数 `0xF513A8` 的常量池）[B]。MH 系列惯例：0.35 = 可捕获线（跛行），0.65 = 陷阱内延长线 → **35%/65% 读法 [I]**，函数级引用未完成。
- 网络同步参数块字段名串池含 `mParam.hokaku_point`（捕获得点）与 `mParam.hp_vital`（HP 同步字段）[B]（flat 0x1559591.. 的 `mParam.*` 名池）。
- 任务记录 `GekitaiHp`（击退血量阈值，rec+0x016）只用于「讨伐或击退」型任务，与捕获无关 [B]。

### 4.2 捕获的玩家规则

1. **只有 HP 低于约 35%** 才能捕获成功；最可靠的时机信号是**跛行**（一瘸一拐换区/回巢睡觉）[I]。
2. 需要**陷阱**（落穴或麻痹陷阱）+ **捕获用麻醉玉**（陷阱中投掷；陷阱有效期内 2 颗内生效）[I]。0.65 常量或对应「陷阱中可捕获的放宽线」，待实机确认 [U]。
3. 任务目标是「捕获」时，**杀死目标 = 任务失败**；目标是「狩猎/讨伐」时，捕获也算完成（报酬按捕获结算）[I]。
4. 古龙种**不可捕获**（陷阱无效）[I]；老山龙等特殊体型怪同样不可。
5. 部位破坏与捕获互不冲突：捕获结算同样拿得到破坏素材 [I]。

## 5. 一页结论（玩家版）

1. **血条是「基础 HP × 任务倍率」**：同一只怪在村、集会所、G 级完全是三个血量；G 级怪血量约是村级同怪的 3–6 倍。
2. **基础 HP 硬数据存在**（每怪 dttune +0x38），主流库（mhgu.db）与 romfs 在已对拍怪上逐字节一致，可放心引用本页表。
3. **部位破坏看外观不看血条**：角/壳/尾各有独立耐久，数值游戏未公开（romfs 有 DTP 文件但语义未解）。
4. **断尾只能用斩系武器**；锤/狩猎笛/弩枪打尾部不累计断尾值。
5. **跛行 = 可以放陷阱抓了**（约 HP 35%）；捕获任务别手滑杀死，狩猎任务捕获不亏。
6. 古龙不能抓，陷阱对它无效。
