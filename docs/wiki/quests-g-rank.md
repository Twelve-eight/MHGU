# 集会所 G★1–G★4 关键任务与紧急任务

> **本页能查到什么**
> 1. G 级（集会所 G★1–G★4）全部 **27 条关键 / 紧急任务**：编号、星级、任务名、目标、目标怪物（含乱入）、地图、时限、报酬金、契约金、HRP。
> 2. 每个星级的 **收口计数**：该星级全部任务条数、关键数、紧急数，以及 G 级主线的推进顺序。
> 3. 本页只列关键 / 紧急。普通追加任务与 HR 门槛见 [quests.md](quests.md) §5–§6，承接条件（HR9 / HR12 / HR13 等）见 [quest-requirements.md](quest-requirements.md)。

**一句话结论**：G★1 关键全清 → G★2 紧急 q11204 出现 → 完成后开放 G★2；依此类推到 G★4。G★4 紧急「废墟之城」完成后，G 级主线结束。

## 1. 怎么读本页

| 项 | 说明 |
|---|---|
| 编号 | `mhgu.db.quests._id`，即 `q<id>`。 |
| 星级 | `quests.stars` 的 11–14 对应 G★1–G★4（`stars - 10`）。[I] |
| 类型 | 关键 = `type 1`；紧急 = `type 2`。与 `quests.json` 的 `keyType` 计数一致。[C] |
| 任务名 | 中文任务名沿用 [quests.md](quests.md) 的 wiki 译名（官方中文任务名不存在）；英文名与 `mhgu.db.quests.name` 逐字一致。 |
| 目标 | 中文怪物名按 [quests.md §1.1](quests.md) 的官方简中表；`（+N 乱入）` 对应 `monster_to_quest.unstable = 1`。 |
| 地图 | 官方简中地图名，取自 [quests.md §1](quests.md)（昼夜分开）。 |
| 时限 | 分钟，`quests.time_limit`。 |
| 报酬金 / 契约金 / HRP | z / z / 点，`quests.reward` / `quests.fee` / `quests.hrp`。只有 `mhgu.db` 一个来源，未与 romfs 对拍 → [I]。 |

## 7. 注意

1. q11105 的目标：[quests.md](quests.md) 第 444 行写「白速龙王」。官方简中表（[quests.md §1.1](quests.md)）中 Giadrome 为「蓝速龙王」。本页采用后者。[X]
2. q11319 与 q11401 的数据库目标是「讨伐，或击退」（`Slay ... or repel it`）。本页保留这一写法。
3. q11432 的数据库目标只有 Ahtal-Ka 一个怪。wiki 注明「阁螳螂·机甲形态」，形态细分不在数据库里。[U]
4. q11406、q11461、q11465 的怒食恐暴龙 / 激昂金狮子使用 `itemData_chS` 的专属叫法；数据库里对应的是变体条目（Savage Deviljho / Furious Rajang）。[I]
