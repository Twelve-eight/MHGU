# 狩猎笛：音色组合与旋律全表（MHGU 1.4.0）

> 1. 狩猎笛的音色只有 **8 种颜色**，按「音色1/2/3」排成 **50 种音色组合**（= 25 组配色 × 2 种排列），落进 25 个「旋律组」。
> 2. 全部旋律共 **52 个表内 id**（其中 3 个是占位「出局！」），**49 条可用旋律**的初回时长 / 叠奏延长时间、官方中文名与效果文本都已逐条列出。
> 3. 全游戏 **796 把**狩猎笛（110 个最终形态）分布在 50 种音色组合上；本页给出每个组合能吹的全部旋律与谱面（音符顺序）。

## §1 记法

### 1.1 八种音色（表内 id 与字母）

字母即 db `weapons.horn_notes` / `horn_melodies.notes` 的写法，来源 db [I]；字母→颜色与 id→字母两张映射都是 **[B]**：把 `.fms` 的谱面与 db 的 `song` 串逐条对照即可唯一确定（见下表「判定依据」）。

| 表内 id | 字母 | 音色 | 可作 | 判定依据（.fms 谱面 ↔ db song） |
|---|---|---|---|---|
| 1 | `W` | 白 | 仅音色1 | 旋律 0 自我强化在 `.fms` 首两条记录为 `(1,1,·,·)`、`(2,2,·,·)`，db 对应 `WW` / `PP` ⇒ 1=白、2=紫 |
| 2 | `P` | 紫 | 仅音色1 | 同上 |
| 3 | `R` | 赤 | 音色2/3 | `Attack Boost (L)` 记录 `(2,4,3,2)` 倒读 = `P R B P` = db `PRBP` ⇒ 3=赤、4=青 |
| 4 | `B` | 青 | 音色2/3 | 同上 |
| 5 | `G` | 绿 | 音色2/3 | `Wind Resistance` 记录 `(3,4,4)/(5,4,4)/(7,4,4)` 倒读 = `B B {赤/绿/空}`，db 为 `BBR`/`BBG`/`BBC` |
| 6 | `Y` | 黄 | 音色2/3 | `Negate Stamina Use (S)` 记录倒读 = `W C B` / `W G B` / `W Y B`，db 为 `WCB`/`WGB`/`WYB` ⇒ 6=黄 |
| 7 | `C` | 空（水色） | 音色2/3 | `Psychic` 记录 `(7,4,1)/(7,4,2)` 倒读 = `W B C` / `P B C` = db `WBC`/`PBC` ⇒ 7=空 |
| 8 | `O` | 橙 | 音色2/3 | 结构性唯一解：只有 `P` 组出现过第 8 色（示例 紫青橙），`W` 组从无 |

> 注意 `W`/`P` 互斥：50 种组合里每个组合的第一个音色必为白或紫（与 4U→GU 移植研究 `.tmp/ext/MH4U-port-to-MHGU/notes/gear-weapons.md:345` 的「colour enum 1 white, 2 purple, 3 red, 4 blue; first note is always 1/2」一致，可作旁证）。
> 颜色中文写法用 wiki 惯例（白/紫/赤/青/黄/绿/空/橙）；官方文本里红色亦写作「红」（见 `weapon12MsgData_chS` 红虫甲笛/绿虫甲笛/白虫甲笛）。

### 1.2 音色1/2/3 对应哪些攻击

官方操作文本 `chS/table/HN_WeaponControlsMsg_chS.gmd`（label `WC_HORN_commandnote_1..6`）：

| 攻击 | 产出音色 |
|---|---|
| 左挥 / 前方攻击 | 音色1 |
| 把柄攻击 / 右挥 | 音色2 |
| 后方攻击 / 敲打 | 音色3 |

- 空中「跳跃连音攻击」可输入 **2 次**音色；精准闪避后的「三连音攻击」可连输 **3 次**音色（同上文件 `WC_HORN_skillnote_5/6`，与 `wiki/styles-arts.md` §4 一致）。
- 把柄攻击恒定发**音色2**（`WC_HORN_skillnote_3`）。

### 1.3 谱面记法

`horn_melodies.song` 是**音色序列**（不是槽位序列）：例如 `PRBP` = 依次演奏 紫→赤→青→紫。因为每把笛只有 3 个音色，同一个旋律在不同组会显示成不同字母串。本页 §3 的谱面列直接抄 db 值。

### 1.4 时长记法

- **初回**：旋律第一次发动后效果持续多少秒。
- **叠奏**：效果已在身上时再演奏一次，可延长的秒数（`2602` 规则：延长不会超过初回时长）。
- 「初回」列照抄 db `duration`；「叠奏」列照抄 db `extension`，前缀 `+` 只表示「延长」。表中「`180 (240)` / `+90 (120)`」即 db 原值加前缀。**括号内的第二个数来自游戏表里存在、但游戏内没有任何文本解释的第二组时长/延长**（见 §6-1）[U]。
- 括号前的数字以 `.fmi` 字节为准 [B/X]。`2602` 与之相符是通例但**不是每一条**：`2602` 的「属性攻撃力強化」写 90/+60，而 `.fmi` 第 30 条记录与 db 都是 `120 (150)` / `90 (120)` —— 按仓库约定 romfs > wiki，本页取 120/+90 [X]（`2602` 该行疑为前作残留 [W]）。
- `0 (0)` = 表内无时长（瞬时效果，如回复、高周波），或该旋律不通过时长实现。

## 附：常用查询

```sql
-- 某把笛的音色组合（db _id 来自 weapons/hunting-horn.json 的 id）
SELECT _id, horn_notes, family, final FROM weapons WHERE _id = 867329;      -- → PBO

-- 某音色组合能吹哪些旋律（含谱面与时长）
SELECT notes, song, name, duration, extension
FROM horn_melodies WHERE notes IN ('WBR','WRB') ORDER BY name;

-- 某旋律出现在哪些音色组合
SELECT DISTINCT notes FROM horn_melodies WHERE name = 'Attack Boost (S)';

-- 每个音色组合的最终形态数
SELECT horn_notes, COUNT(*) FROM weapons
WHERE wtype='Hunting Horn' AND final=1 GROUP BY horn_notes;
```
