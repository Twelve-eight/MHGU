### 1.2 精准跳伤与跳动周期公式（`0x2a49c0` + `0x2f5170` + `player\param\pl_com`）

1. **总持续秒数计时器**：`[player + 0x288c]` 按秒保存毒持续时间，每经过 `[player + 0x2890] = 60.0f` 帧（`0x2f45a8`: `movt r1, #0x4270`）减 1 秒。在紫毒姬 `em001_04_attackdata` 中，重甩尾/空翻 `gu_u18 = 16 s`，重横扫 `20 s`，超级后空翻 `25 s`，毒棘弹壳 `01_hitdata[17/18]` 为 `6 s`。
2. **单跳扣血量（`0x2a4aa0..0x2a4b20`）**：
   - Tier 1 普通毒：`r5 = 1` HP/跳（`0x2a4ad4`）；
   - Tier 2 猛毒：`r5 = 2` HP/跳（`0x2a4adc`）；
   - Tier 3 剧毒：`r5 = 2` HP/跳（`0x2a4ab4`）；
   - 负面技能「毒倍化」（`skill 2` at `0x2a4b0c`）执行 `mov r5, r5, lsl r0` 使单跳翻倍。
3. **跳动周期查表（`0x2f5170` -> `0x282828(player, id)` -> `player\param\pl_com` `FUP` 浮点表 `off 0x6c`）**：
   - `pl_com`（`884 B`，`magic="FUP\0"`，`intCount=22`，`floatCount=122`）在 `f[12..17]` 存放三组精确 `(T, T/2)` 帧间隔：
     - **`id = 12`（普通毒）**：`f[12] = 60.0` 帧（`1.000 s`） -> **`1.00 HP/s`**（`1.0×` 基准）；
     - **`id = 14`（猛毒）**：`f[14] = 40.0` 帧（`0.667 s`） -> **`3.00 HP/s`**（`3.0×` 普通毒）；
     - **`id = 16`（剧毒）**：`f[16] = 24.0` 帧（`0.400 s`） -> **`5.00 HP/s`**（**`5.0×` 普通毒 / `1.67×` 猛毒**）。
4. **「毒无效」对剧毒的精确降级逻辑（`0x2f4498..0x2f44f4`）**：
   - 猎人携带毒无效技能（`skill 1 / 0x137 / 0x143` 或 buff `25`）时，代码清零普通毒 `r6` 与高阶标志 `r8`，但**将原 Tier 3 剧毒 `r3` 保留于 `r5` 并降级施加为 Tier 2 猛毒**！
   - 同时紫毒姬 `em001_04_attackdata` 的 16 组毒攻呈严格**偶/奇成对设计**：偶数行（`0, 2, 4, ..., 36` 及 `01_hitdata[18]`）为 `u14 = 0x08`（断尾前剧毒），奇数行（`1, 3, 5, ..., 37` 及 `01_hitdata[17]`）为 `u10 = 0x10000`（破尾后降级为猛毒），`01_hitdata[15]` 为 `u10 = 0x02`（完全断尾后普通毒）。
5. **对 MHRS `gu_deviant_gimmicks.lua` 的校准启示**：
   - 我们目前在 Rise 中把猛毒（`DebuffType=9`）按 `2.5×` 加速近似剧毒（且断尾降级 `9->8`），在量级上非常接近 MHGU `5.0 HP/s`；若后续实机反馈希望进一步贴合原版，可考虑在「毒耐性 Lv3」下不再完全免疫，而是降级为不加速的普通/猛毒（待你实机体验后定夺）。
