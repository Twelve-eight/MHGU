### 2.2 风格分发入口与武器子类虚表覆写（以 `w07` 太刀、`w13` 操虫棍为例） `[C]`

- **统一风格查询虚函数**：虚表 `slot 90`（`+0x168` = `#360`）返回当前狩猎风格枚举 `0..5` `[C]`（各枚举值与英文风格名的逐号对应仍标 `[B]`，待结合存档 `mStyle` 交叉固化）。
- **关键子类覆写槽位**：
  - `slot 139 (+0x22c)`：基类 `0x27e770` -> `w07: 0x1199114` / `w13: 0x11cbd88`（武器状态与资源前置更新）；
  - `slot 187 (+0x2ec)`：基类 `0x268a8c` -> `w07: 0x1198bb4` / `w13: 0x11cb9cc`（按风格 `0..5` 分支查表处理特殊条件）；
  - `slot 201 (+0x324)`：基类 `0x268ac0` -> `w07: 0x11998b0` / `w13: 0x11cca24`（**主动作状态机分发器**，按 `*(u16*)(this + 0x250a)` 跳转各招式处理函数）；
  - `slot 248 (+0x3e0)`：基类 `0x2a01d4` -> `w07: 0x1198ab4` / `w13: 0x11cb6d4`；
  - `slot 314 (+0x4e8)`：基类 `0x2a4320` -> `w07: 0x119eef0` / `w13: 0x11d2dfc`。

## 3. `LMT` 动作头 `+0x34` 四组帧事件通道语义

### 3.1 加载重定位与逐帧求值链（`0x00b49fe8` -> `0x00280984`） `[C]`

1. **`rMotionList` 加载重定位（`0x00b49fe8..0x00b4a054`）**：
   - 将 64 B 动作头 `+0x34` 处的 `eventOffset` 重定位为 `lmtBase + eventOffset`；
   - 当 `(motionHeader[0x33] & 2) == 0` 时，依次将 4 个间距 `0x48`（72 B）的事件槽数组指针加上 `lmtBase`：
     - **Slot 0**：`count` @ `+0x40`，`arrayPtr` @ `+0x44`
     - **Slot 1**：`count` @ `+0x88`，`arrayPtr` @ `+0x8c`
     - **Slot 2**：`count` @ `+0xd0`，`arrayPtr` @ `+0xd4`
     - **Slot 3**：`count` @ `+0x118`，`arrayPtr` @ `+0x11c`
   - 每个数组元素为 8 字节 `{ u32 mask, u32 duration }`，各段 `duration` 之和等于动作 `frameCount`（末尾通常以 `{ 0, remaining }` 哨兵收尾），可通过 `node tools/mhgu/lmt.mjs events <file.lmt> [motionIndex|--all]` 直接导出。
2. **玩家逐帧求值函数（`0x00280984`，由 `0x2820b4` 调用）**：
   - 根据当前动作槽 `*(u16*)(this + 0x4b4)` 与当前帧 `(u32)*(f32*)(this + 0x500)` 逐槽累加 `duration` 直至 `sum > frame`，将命中的 `mask` 分别写入 `this + 0x14dc / +0x14e0 / +0x14e4 / +0x14e8` `[C]`。
