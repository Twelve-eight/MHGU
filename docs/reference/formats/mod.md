# MHGU MOD v212（模型）

工具：`tools/mhgu/mod.mjs`（`info` / `obj`）。样本：雄火龙 em001_00/02/04、雌火龙 em002_00、角龙 em007_00、麒麟 em011_00，以及各自的 `_tail`。这些样本只放在 `MHGU-private/`，不入库。

ARC 类型哈希：MOD = `58a15856`，TEX = `241f5deb`，MRL = `2749c8a8`，LMT = `76820d81`，XFS = `7cd0e77e`。

参考：Silvris/MH-Tools-and-Scripts 中的 `MHGU MOD.bt`。该仓库无许可证，这里只吸收事实；凡标 [C] 的条目都已在样本上独立验证。

- 组：每条 32 B {u32 id, 3 × f32 0, f32[4] 包围球}。

## 顶点位置 [C]

- 格式 `5e7f2030`（步长 28，静态网格）：3 × f32。
- 其他格式：3 × u16，`pos[k] = bboxMin[k] + raw[k] × Q`，其中 `Q = (max(bboxMax) - min(bboxMin)) / 32767`。这是一个立方量化盒，三轴共用一个比例。
  - 判据：用每轴原始最大值反推出的比例，在 em001 / em002 / em007 / em011 上与公式一致到 5 位小数。
  - 反例：按轴单独用 /65535 或 /32767 归一化，模型会变形。
  - 肉眼：四只怪的线框正面和侧面轮廓都正确。

样本里出现的格式与步长：`cb68015/20`、`b3921020/36`、`64593025/40`、`db7da014/16`、`d877801b/32`、`a8fab018/20`、`14d40022/28`、`5e7f2030/28`。法线、UV、权重在各格式里的布局 [U]。

### 蒙皮字段（2026-10-24）
所有格式开头都是位置 3 × u16（+0）。蒙皮格式的 +6 是 s16 权重 w0，除以 32767。下表的骨号都是 MOD 局部骨号，取值小于文件骨数。

| 格式 | 名字 | 骨号 | 其余权重 | 证据 |
|---|---|---|---|---|
| `14d40022`、`64593025` | IASkinTB4wt | 4 × u8 @+16 | w1、w2 = 2 × f16 @+24，w3 = 1 − 和 | [C] |
| `db7da014` | IASkinBridge2wt | 2 × u8 @+12 | w1 = 1 − w0 | [C] |
| TB1wt | IASkinTB1wt | u8 @+6 | 无 | [C] |
| `c31f201d`（步长 24） | IASkinTBN2wt | 2 × **f16** @+20 | w1 = 1 − w0 | 3 个模型 24/24：整数，小于 N，w0 < 1 时两骨不同；对照：按 u16 读，0/24 小于 N |
| `b3921020`（步长 36） | IASkinTBNLA2wt | 2 × **f16** @+16 | w1 = 1 − w0 | 同上 |

- 法线是 3 × s8 @+8，长度约 127（24/24）。
- `b3921020` 的 +20 处 f16 × 2 在 +32 处重复了一遍，像是 UV [I]。
