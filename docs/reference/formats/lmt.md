# MHGU LMT v0x43（动作）

工具：`tools/mhgu/lmt.mjs`（`info` / `dump`）。样本是 em001/002/007/011 的 34 个动作文件，只放在 `MHGU-private/`。

## 结构
- 头：`LMT\0`、u16 版本 0x43、u16 条目数，然后是条目数个 u32 条目偏移（0 = 空）。
- 条目（0x40 B）：+0 轨表偏移、+4 轨数、+8 帧数。
- 轨（0x24 B）：u8 类型、u8 用途、u8 ?、u8 骨号（游戏骨 id，经 MOD 的 256 B 重映射表换成文件内骨序号 [I]）、f32 权重、u32 字节数、u32 键偏移、f32[4] 参考值、u32 bounds 偏移。
- bounds（0x20 B）：f32[4] A，后接 f32[4] B；值 = B + A × 归一化值。
- 每个键的帧增量在该键的最高 4 位（type 6 为最高 8 位）[C]：
  - 每条轨的最后一个键都落在帧数-1 上，24633/24633；
  - 对照：改从低位取增量，0/15258。
