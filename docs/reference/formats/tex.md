# MHGU TEX（Switch，版本 0xA0）

工具：`tools/mhgu/tex2dds.mjs`，输出第 0 级 mip、DX10 头的 DDS。样本：雄火龙、雌火龙、角龙、麒麟的 21 张怪物贴图全部解码正确（肉眼确认），只放在 `MHGU-private/` 里。

## 头部（小端）

| 偏移 | 内容 | 证据 |
|---|---|---|
| 0 | `TEX\0` | [C] |
| 4 | u32，样本全为 0x200080A0（低 8 位 = 版本 0xA0；高 4 位 = 类型，6 = 立方图 [I]） | [C] / [I] |
| 8 | 位域：mip 数 6 位、宽 13 位、高 13 位（低位在前） | 387 个文件 [C] |
| 12 | u8 面数、u8 格式、u16 深度 | [C] |
| 16 | u32 数据区总字节 | 加头部正好等于文件长 [C] |
| 20 | mip 数 × u32：各级 mip 相对数据区的偏移 | [C] |
| 20 + 4 × mip 数 | 数据区 | [C] |

## 数据
- Tegra X1 块线性排布：GOB 为 64 B × 8 行，块高 16 个 GOB；以 4×4 压缩块（或像素）为元素 [C]。
  - 判据：按线性直接读出是噪声，按块线性还原后图像正确；块高取 1/2/4/8 时图像错位。
- 每级 mip 的步长 = max(该级块大小, 512 B)：尾部小于一个 GOB 的 mip 补到 512 B，只按 W×H 算块大小求和会比数据区小 [C]。
  - 证据：`em001_00_BM`（BC3 1024²，11 级）mip 偏移 0 / 1048576 / 1310720 / 1376256 / 1392640 / 1396736 / 1397760 / 1398272 / 1398784 / 1399296 / 1399808 → 前 6 级等于块大小（最后一级 1024），后 5 级各 512 B，而块大小只有 256/64/16/16/16；数据区 1,400,320 = 1,397,760 + 5 × 512 = 文件长 1,400,384 − 64。`em001_00_BM+A`（BC4，699,064 + 2,376 = 701,440）与 `em001_00_NM_MIRROR`（BC5）同规则。
  - 全量：本工作区 383 个 `*.241f5deb`（格式 0x07 ×363、0x13 ×3、0x17 ×6、0x19 ×6、0x1F ×5）383/383 满足「头 + 数据 = 文件长、mip 偏移自 0 连续、每级步长 = max(块大小, 512)、步长和 = 数据区字节」[C]。
