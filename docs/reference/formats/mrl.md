## 头部（28 B）
| 偏移 | 内容 |
|---|---|
| 0 | `MRL\0` |
| 4 | u32 版本 34 |
| 8 | 材质数 |
| 12 | 贴图数 |
| 20 | 贴图表偏移 |
| 24 | 材质表偏移 |

类型哈希按 `~crc32(ASCII) & 0x7fffffff` 计算：对 "rTexture" 得 `a41f5deb`、文件里存 `241f5deb`；对 "rModel" 得 `d8a15856`、存 `58a15856`（= MOD 扩展名）[C]。
名字哈希**不做这个掩码**，保留第 31 位：`XfB__m01_eye` 的 `~crc32` 是 `0xd1930ba0`，材质描述 +4 存的也是 `0xd1930ba0`（掩码形式 `0x51930ba0` 查不到任何东西）[C]。
全量：**490** 条材质描述（本工作区全部 225 个 `*.2749c8a8`）中 **284** 条名字哈希第 31 位为 1；**490/490** 条都能按完整 32 位对上同目录 MOD 的材质名（`mrl.mjs modnames` 逐文件跑完 225 个，0 条未解析）。旧文记 401/417 且 `cm100_010`/`cm202_041` 有 16 条对不上，是当时 MOD 未补齐所致 [C 2026-11-03]。

各块互不重叠，正好铺满文件。

## 材质块
- 先是 n 条 12 B 资源条目，后面是 16 B 对齐的浮点区。
- 条目类型 = 字节 0 的低 4 位：
  - **1** = 常量缓冲，+4 是块内偏移 [C 980/980 在块内]。
  - **3** = 贴图，+4 是贴图表的 **1 起序号**，0 表示无 [C 1007/1007 落在 0..贴图数内；其中 448 条为 0]。+8 是槽位哈希；同一槽位在不同材质间哈希不变。
  - **0 / 2** = 哈希引用，由全局管理器解析 [I]。
- em001 的绑定：body 用 1/2/3（NM_MIRROR、BM、BM+A），翅膀用 1/2/2，眼睛只用 2。
- 槽位与常量缓冲的可读名 [U]，需要 shader 包里的哈希字典。
