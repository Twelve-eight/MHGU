## 顶层调度器 `0x3e77b0`
`bl`/`b` 序列 = 存档成员的**文件序列化顺序**。rodata 表 `[0x3e7938..0x3e7980]` 存的是 **PC 相对偏移**（`ldr rX,[pc,#imm]` 取偏移 → `ldr rX,[pc,rX]` 解析到 GOT 槽 → `ldr rX,[rX]` 取成员单例）。**勘误**：早期记的「19 个 `0x145xxxx` 对象指针」不准确，它们是偏移量。

## 三类读原语（反序列化工具函数）
| 原语 | 语义 |
|---|---|
| `0x3df2a8` | 定长原始块读（memcpy 式，r1=目标 r2=size）|
| `0x3df378` | 定长原始块**写**（序列化版）|
| `0x3df1b8` | **位宽计算**——返回**容纳 r1 所需的最小位宽**（1..32），不是返回 r1 本身：从 32/24/16/8 bit 的掩码起，掩码右移 1 位直到小于 r1，返回对应位宽（实测 cap 3→2、9→4、6→3、10→4、2→2、99→7、`0xbaf`→12）。位流字段的 size 是**位宽**，把 cap 当位宽会算大 |
| `0x3df22c` | **位流读**——`ldrb`+掩码+位计数器，返回位打包值；配 `0x3df1b8` 构成 **u16 位流数组**读取 |
| `0x1ac014`/`0x277454` | member[16]/[18] 的子 reader |

## 坐标系与对齐
- `bl` 顺序 = 文件顺序；member[2] = **成员#4 外层**（DEVELOP.md 的 member#4 是其内层子对象 `0x51dc40`）
- member[0]/[1] = **位打包 u16 物品数组**（`0x3df1b8`+`0x3df22c` 编码），非字符串——修正初版误判
- member[3] = **装备箱**（2000 玩家 + 1000 猫装备 + 5440B 套装 + 1632B 尾，`EquipsForm` 操作对象）
- obj_off 相对各成员对象基址 `r5`（=`ldr[r5,#0]`），≠ file_off；各成员 file 基址按序列化顺序累加前序 size 定位
