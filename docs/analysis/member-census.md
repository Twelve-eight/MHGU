# 成员 Census — 顶层序列化器反汇编定案（2026-10-23）

## 顶层调度器 `0x3e77b0`
`bl`/`b` 序列 = 存档成员的**文件序列化顺序**。成员对象指针来自 rodata 表 `[0x3e7938..0x3e7980]`（19 个 `0x145xxxx` 指针）。调度器共 **20 次调用**（19 `bl` + 1 尾跳 `b 0x2282a8`），覆盖 **19 个独立成员对象**——`0x3e7920` 的 `bl 0x521398` 用 `[r5,#0]`，r5=`0x3e77e4` 装的 `*0x145159c`，与 member[2] `0x51dbb4` **同一成员单例**，是 member[2] 的第二段 reader。

`0x3e7984` 起紧跟第二个同构函数（另一套 tbl `@0x3e7be8+`：`0x1451380/0x14511a0/0x14537b8/0x1452ea4/0x145115c…`）——**序列化/写入侧**的成对调度器（读 `0x3df2a8`↔写 `0x3df378`）。

## 三类读原语（反序列化工具函数）
| 原语 | 语义 |
|---|---|
| `0x3df2a8` | 定长原始块读（memcpy 式，r1=目标 r2=size）|
| `0x3df378` | 定长原始块**写**（序列化版）|
| `0x3df1b8` | **位宽计算**——按 r1 选 8/24/32bit 宽度+掩码（`0x7f/0x7fff/0x7fffffff`）；位流字段位宽上限 |
| `0x3df22c` | **位流读**——`ldrb`+掩码+位计数器，返回位打包值；配 `0x3df1b8` 构成 **u16 位流数组**读取 |
| `0x1ac014`/`0x277454` | member[16]/[18] 的子 reader |

## 坐标系与对齐
- `bl` 顺序 = 文件顺序；member[2] = **成员#4 外层**（DEVELOP.md 的 member#4 是其内层子对象 `0x51dc40`）
- member[0]/[1] = **位打包 u16 物品数组**（`0x3df1b8`+`0x3df22c` 编码），非字符串——修正初版误判
- member[3] = **装备箱**（2000 玩家 + 1000 猫装备 + 5440B 套装 + 1632B 尾，`EquipsForm` 操作对象）
- obj_off 相对各成员对象基址 `r5`（=`ldr[r5,#0]`），≠ file_off；各成员 file 基址按序列化顺序累加前序 size 定位

## 与已测绘区对应
- member[2] 内层 `0x51dc40` = 已全标注的 134 字段成员#4（`member4-semantics.md`）
- member[2] `obj+0x72C/0x83E` 274B = 怪物击杀/捕获 137 槽（`monster-slot-map.md` 的代码侧实证）
