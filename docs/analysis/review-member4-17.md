## 4. 位流：字节对齐与位宽

### 4.1 没有 4 B 对齐；字节成本 = `ceil(bits/8)`

`0x3df2a8(ctx, dst, size)` 的关键指令（注意 `!` 写回；反汇编器未打印 `!`，但编码 `e5b50008`/`e5b52008` 的 W=1）：

```
0x3df2b4  ldr  r0,[r5,#4]        ; ctx+4 = 位号
0x3df2b8  cmp  r0,#0
0x3df2bc  beq  0x3df2d8
0x3df2c8  ldr  r0,[r5,#8]!       ; r0 = ctx->ptr；r5 被写回成 ctx+8
0x3df2cc  add  r2,r0,#1
0x3df2d0  str  r2,[r5,#0]        ; ctx->ptr = ptr+1（跳过被部分消费的 1 字节）
0x3df2dc  … memcpy(dst=r1, src=r2, size)
0x3df2ec  ldr  r0,[r5,#0]        ; r5 已是 ctx+8，读回 ctx->ptr
0x3df2f0  add  r0,r0,size
0x3df2f4  str  r0,[r5,#0]        ; ctx->ptr += size
```

`0x3df22c` 的位读按 **8 bit/字节** 前进（`cmp lr,#6; bhi` 在 lr=7 读完后回绕、`ctx+8 += 1`），不是 4 B 对齐。

⇒ **位流消耗 = `ceil(bits/8)`**，且仅当位流后接**字节读**时才发生 1 字节的“跳过部分字节”；若位流恰好 8 bit 对齐（如 m[5] 的 94×32 = 3,008 bit = 376 B），则不跳。

- m[5]：376 B ✓（报告 376）。
- m[17]：2 bit → 1 B ✓（报告 1）。
- m[7]：见 E1，正确是 157 bit → 20 B（报告 25 B）。
- 报告风险 4 的“4B 对齐未验证、±3 B”可以关闭：**不存在 4 B 对齐**；m[7] 的 ±5 B 来自位宽，不来自对齐。

### 4.2 m[7] 位宽：cap ≠ width（E1）

`0x3df1b8` 的语义（`0x3df1b8..0x3df224`，逐条核对）：由 cap 求“能容纳 cap 的最小位宽”，用掩码 `0x7F/0x7FFF/0x7FFFFF/0x7FFFFFFF` 逐次右移，返回 `位宽`。手算：

| cap | 返回位宽 | 校验 |
|---|---|---|
| 3 | **2** | 2 bit 最大 3 ✓ |
| 9 | **4** | 4 bit 最大 15 ✓ |
| 6 | **3** | 3 bit 最大 7 ✓ |
| 10 | **4** | 4 bit 最大 15 ✓ |
| 2 | **2** | （m[17] 用）✓ |
| 99 | **7** | 与 `save-load-path.md` row 1 的 `(99)→7bit` 一致 ✓ |
| 0xBAF=2991 | **12** | 与 row 1 的 `(0xbaf)→12bit` 一致 ✓ |

m[7] 的 12 处位读（`0x263a0c..0x263b28` + `0x263b30..0x263b7c`）：

- cap 3 / 9 / 6 / 10×5 → 位宽 **2/4/3/4×5 = 29 bit**；报告的 3/9/6/10×5 = 68 bit 是把 cap 当成了位宽。
- 4×`mov r1,#32; bl 0x3df22c` → 128 bit（报告正确）。
- 合计 **157 bit = 19.625 B**，后接 `0x263bb4 bl 0x263368`（字节读）⇒ 消耗 **20 B**（`ceil` + 跳 1 字节），不是 25 B。

外部校验（独立于本报告）：

- `save-load-path.md` row 9 的 m[7] size 就是 **35,131**；row 10 起点 `0x2C4D8`。`0x23B9D + 0x893B = 0x2C4D8` ✓；若用 35,136（0x8940），终点是 `0x2C4DD`，会**侵入 member[10] 块 5 B**。
