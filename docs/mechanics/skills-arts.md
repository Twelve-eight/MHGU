## 核心机制

### 1. 技能点数与发动

#### 1.1 阈值体系

技能树的每个「档」由一个绝对值阈值触发，**档位互斥**（只取已达到的最高正向档 / 最低负向档），不是累加。

| 阈值 | 出现树数（共 204） | 含义 |
|---|---|---|
| `+20` | 6 | 最高正向档（如 攻击力UP【大】、洞察+3、装填速度+3） |
| `+15` | 50 | 次高档 |
| `+10` | **204（全部树）** | 基础发动档：任何技能树 10 点必发动 |
| `-10` | 48 | 基础负向档 |
| `-15` | 13 | 中等负向档 |
| `-20` | 5 | 最强负向档 |

引擎侧对应 `cSkillBaseXML`（vaddr `0x1567e08`）的三个成员名 `mSkillPlus10` /
`mSkillMinus15` / `mSkillPlus20`，与上表 10/15/20 的量级吻合（成员名只覆盖 3 个阈值，逐档映射为
**[未确认]**）。

#### 1.2 档位组合分布（两源一致）

按「同一树的全部阈值」分组（`skill_tree_id` → 阈值集合）：

| 阈值集合 | 树数 | 代表树（JSON id） |
|---|---|---|
| `[10]` | 136 | 7(Bind Res)、8、11… |
| `[10,-10]` | 18 | 1(Poison)、2、3、9、10、17、32、34… |
| `[10,15]` | 20 | 5(Hearing)、6、16、35(Handicraft)、53… |
| `[10,15,-10]` | 17 | 4(Stun)、21-25(五属性耐性)、27-31(五属性攻击)、33 |
| `[10,15,-10,-15]` | 7 | 20(Health)、47、79、118、121、128、134 |
| `[10,15,20,-10,-15,-20]` | 5 | 18(Attack)、19(Defense)、45(Reload Spd)、46(Recoil)、70(Expert) |
| `[10,15,20,-10,-15]` | 1 | 135(Fate/运气) |

⇒ **只有 5 棵树拥有完整 6 档**（攻/防/装填速度/后坐力/达人）；运气是唯一「有 +20 但负向只到 -15」的树。
合计：136（仅 `[10]`）+ 48（含负向档）+ 20（`[10,15]`，无负向档）= 204。

#### 1.3 发动的三个非显然规则

1. **复合技能是独立树**：如「斩术」= 心眼+利刃，但它本身是 1 棵树，需自身 10 点；不会由心眼/利刃各 10 点自动合成。
2. **技能点可被「放大」或「加倍」**（见 §2）：`护石强化` 使护石点数翻倍、`身体系统加倍` 使胸部件点数 ×2、`秘术` 给全部技能点 +2。
3. **同一树的正负档不会同时存在**：`攻击力UP【小】` 与 `攻击力DOWN【小】` 由同一棵「攻击」树的符号决定，
   存档里没有「已发动技能列表」字段（见 §存档关联）。

### 2. 点数来源与上限

| 来源 | 容量 | 说明 |
|---|---|---|
| 防具 5 部位（头/胴/腕/腰/脚） | 每件 **最多 5 条**技能点 | 引擎名表 `mHeadSkillPoint[0..4]` / `mTorsoSkillPoint[0..4]` / `mArmSkillPoint[0..4]` / `mWaistSkillPoint[0..4]` / `mLegSkillPoint[0..4]`，各 5 下标 |
| 护石（talisman） | **2 条** | `mAccSkillType1/2`（技能 id）+ `mAccSkillPoint1/2`（点数，**可为负**） |
| 装饰珠 | 最多 **21 孔** = 武器 3 + 防具 5×3 + 护石 3 | 三处数据源 `num_slots` 上限均为 3（`json/weapons.json`、`json/armor.json`、护石记录 `+16`） |
| 秘术（Secret Arts, 树 id 204） | 全部技能点 **+2** | wiki 2206 原文「装备技能点数的合计值+2」；按字面「合计」无法影响任何档，故按「每树 +2」理解 **[推断]** |
| 身体系统加倍（树 id 25，点数 0） | 胸部件点数 ×2 | wiki 2206 原文；该树自身点数恒为 0（不是靠点数发动） |
| 护石强化（Talisman Boost, 树 id 205） | 护石点数 ×2 | wiki 2205：`护石系统加倍` @10 点「护石技能点翻倍」 |
| 武器 | **无固有技能点** | 武器只提供孔 |

理论最大单树点数（21 孔全插同一技能的三孔珠 + 满点护石 + 5 部位装备）远超 20，故 20 档不构成硬瓶颈。

### 3. 装饰珠（242 条）

#### 3.1 孔数 × 点数（`decorations.json` 全表统计）

| 珠孔数 | 条数 | 正向点数取值 | 条数分布 |
|---|---|---|---|
| 1 孔 | 156 | `+1`（主力技能）/ `+2`（廉价技能） | +1:97 / +2:59 |
| 2 孔 | 46 | `+3` | 46 |
| 3 孔 | 40 | `+4`（多数）/ `+5`（仅 3 条） | +4:37 / +5:3 |

`+5` 的 3 条：`Attack Jwl 3`（攻击 id 18）、`Expert Jwl 3`（达人 id 70）、`Sane Jwl 3`（狂龙耐性 id 15）。
wiki 2208 的规格描述与此一致：「装饰品数量为 3 时 1S1 / 2S3 / 3S5（达人、攻击等），或 1S1 / 3S4（超会心等）」。

#### 3.2 双效果与副作用

- 242 条中 **182 条**带 2 个技能效果（正面 + 负向副作用），**60 条**只有 1 个效果。
- 副作用恒指向**另一棵树**且点数很小：`-1`（146 处）/ `-2`（36 处）。
  例：`Attack Jwl 3` = 攻击 `+5` + 防御 `-1`；`Handicraft Jwl 3` = 匠 `+4` + 锋利度 `-2`。
- 珠只覆盖技能树 **id 1..143**（普通技能 + 6 个村庄之心），**复合技能（id 144..205）无装饰珠**。

#### 3.3 单效果珠（60 条）

除 1 孔廉价珠外，包含少数 3 孔单效果珠：`Bladescale Jwl 1/3`（刃鳞）、`Charmer Jwl 1/3`（护石收集）。
这类珠不产生副作用，是「纯收益」孔位填充。

#### 3.4 「无洞护石即可发动」的分界

wiki `2208` 把技能表**拆成两页**：「无洞护石可发动的技能」与「有洞护石可发动的技能」。按图例，判据是
**仅凭护石本身的点数（不借助护石孔里的珠子）能否达到该技能的基础 10 点阈值**：

- 无洞页前列是「护石上限 ≥10」的廉价技能（采集 10\|13、贪吃鬼 10\|13、调和成功率 10\|13、反复无常 10\|13、
  昏厥 8\|13、体力 8\|13 等）。
- 有洞页 = 护石上限 <10、必须靠护石孔里的珠子补足的技能（如 耐震 7\|8、通常弹追加 8\|8、雪人 7\|8）。
- 两页的分界只取决于「护石上限 vs 10」，与技能树自身的 15/20 档无关。
- 注意：`a | b` 两列的精确语义仍未定案（见 §未确认 #9），此处只使用「技能落在哪一页」这一二元事实，
  不引用具体数值做推导。

### 4. 复合技能（65 条）

- **全部是单档 10 点**（wiki 2207 每条只列一个 `10`），无负向档、无 15/20 档。
- 构成：6 个村庄之心（贝鲁纳/可可特/波凯/结云/龙识船/飞行酒吧，各只有 1 件防具提供 10 点）+
  18 个二名（`红盔`…`鏖魔`，各 10 件装备）+ 18 个「真·」G 级版本 + 23 条通用复合
  （北辰/海渊纳豆流、斩术、食欲、工人、铁臂、祈愿、掩人耳目、刀匠、射手、状态耐性、怒、闪避术、
  居合、顽强、刚击、持盾、洁癖、増幅、护石收集、强欲、对钢龙、对霞龙、对炎龙）。
- JSON 归类差异：`skills.json` 把 138..143 记为村庄之心、144..179 记为二名/真·二名、180..202/204/205
  记为其余复合，且把 `秘术`(204) / `护石强化`(205) 也放进复合区段；wiki 则把这两条当普通技能列在 2206。
  **两边的点数结论一致（单档 10）**。

代表条目（效果原文见 2207）：

| 技能系統 | 发动技能 | 点数 | 效果 |
|---|---|---|---|
| 刀匠 | 真锻 | 10 | 锋利度等级+1 + 攻击力UP【大】 |
| 斩术 | 人剑一体 | 10 | 心眼 + 利刃 |
| 刚击 | 无情 | 10 | 洞察+2 + 弱点特效 |
| 射手 | 刚弹 | 10 | 通常弹/连射矢UP + 贯通弹/贯通矢UP + 散弹/扩散矢UP |
| 怒 | 逆鱗 | 10 | 火场怪力+2 + 毅力 |
| 増幅 | 属性兼道具强化 | 10 | 属性攻击强化 + 道具使用强化 |
| 状态耐性 | 护法 | 10 | 毒/麻痹/睡眠/昏厥 四无效 |
| 飞行酒吧 | 飞行酒吧之心 | 10 | KO术 + 吹笛名人 |
| 鏖魔 | 鏖魔之魂 | 10 | 攻击力UP【大】 + 回避性能+2 |
| 真·鏖魔 | 真·鏖魔之魂 | 10 | 攻击力UP【大】 + 回避性能+2 + 明镜止水 |

弹道强化 + 急速磨刀）；两者是**不同的树**，不会互相覆盖。

### 5. 负向技能与护石合法性

- **护石负点数合法（已定案）**：仓库契约明确「负 LV 合法（Attack -5）」，编辑器 NUD 的 `-50..50` 是
  有意设计，不得当 bug 或钳到 0（`DEVELOP.md`「假阳性拦下」、`.tmp/reports-mhgu/review-equips-cats.md` P 系列）。
  存档里护石两条技能的等级字段是 **sbyte**（`+14` / `+15`），可直接存负值。
- 负向档共 48 棵树具备；`-10` 是最常见档（48 棵），`-20` 仅 5 棵（攻/防/装填速度/后坐力/达人）。
- 负向效果实例（wiki 数值）：攻击力DOWN【大】-20 → 攻击力 **-15**；洞察-3 -20 → 会心率 **-15%**；
  防御力DOWN【大】 -20 → 防御力 ×0.9 -10（下限 1）；体力-30 -15 → 体力上限 **-30**。
- 护石 + 珠 + 防具负点是**同一套加法**：装备一件带 `攻击 -2` 的部件与插一颗 `攻击 -1` 的珠等价，
  因此「负护石」可以被正珠抵消，反之亦可。

### 6. 狩技（Hunter Arts）

#### 6.1 规模与槽位

| 项 | 值 | 依据 |
|---|---|---|
| 狩技总数 | **66** = 共通 10 + 14 种武器 × 4 | 1847 |
| 每条狩技的等级 | 共通技**只有 1 级**；武器技 **LV1 / LV2 / LV3** | 1847 |
| 可装备槽位 | **3** | 引擎 `mSuperArts1 / mSuperArts2 / mSuperArts3`（`cAcPlayerEquip`）+ 存档 3 组 24B 记录 |

| 狩技槽（gauge） | 战斗中累积，具体每技消耗值 **wiki 未收录** | [未确认] |
| 等级提升的收益 | 伤害/持续时间/效果随 LV 提升（数值 wiki 未收录） | [未确认] |

引擎侧每件狩技的静态数据带 `mArtsCategory`（分类）与 `mArtsGaugeSPType`（**是否 SP 型**）两个字段
（name-dictionary vaddr `0x1567d9f` / `0x1567dd3`）——即「哪几条狩技是 SP 型」是**数据驱动**的，
wiki 页面没有标注该标志位，列表 [未确认]。

**6 个狩猎风格**（wiki 侧的取证）：`1950`-`1963` 的按键表列出 **工会 / 强袭 / 空战 / 武士道** 四列
（MHX 时代的四风格），`2201` 的「无心 / 忍耐」两技能又明确提到 **勇气槽 / 炼金槽** ⇒ 合计 6 个风格：
工会（Guild）/ 强袭（Striker）/ 空战（Aerial）/ 武士道（Adept）/ 勇气（Valor）/ 炼金（Alchemy）。
`cTrialArts` 的 6 个成员名与风格的硬对应只有 4 个已定（`mGuild` / `mAirhike` / `mBushi` + 1），
其余（`mOld` / `mKizuna` / `mTatsujin`）仍为候选（`docs/analysis/fields/fam-288.md` §9.5）。

#### 6.2 解锁轨结构（重要规律）

每条武器 4 个狩技分属 **4 条固定解锁轨**，同轨的 LV1 条件完全相同：

| 轨 | LV1 条件（同轨全部相同） | LV2 | LV3 | 数量 |
|---|---|---|---|---|
| A | **初始任务** | 统一为 `村★4 幻惑的魔術師 和 集★3 电的叛逆者` | 每技不同（集★5/6/7） | 14 |
| B | `村★2 跳跃的不法者 和 集★2 雪山的主、雪狮子王` | 每技不同（猎猫 LV / 村贡献度 400 / 集★3-5 / 斗技大会） | 每技不同 | 14 |
| C | `村★3 制服鬼面猎人 和 集★3 电的叛逆者` | 每技不同（村★5/★6、集★3-5） | 每技不同 | 14 |
| D | `村★7 调査队初阵！遗群岭的桃毛兽 和 集★7 小试牛刀？` | **G★2 任务**（每技不同一个 G★2） | **G★4 任务**（每技不同一个 G★4） | 14 |

⇒ 4 条轨各 14 条（14×4 = 56）+ 共通 10 = 66；A 轨的 LV2 是全表唯一的「完全统一」条件，
D 轨的 LV2/LV3 则统一为 G★2/G★4 各一个任务（**G 级狩技必须打过对应 G★2 才开 LV2**）。

#### 6.6 SP 状态

- SP 状态**不是狩技槽的替代**：使用 SP 型狩技时，给同区域（含猎猫/随从猫）附加 SP 状态；wiki 没有列出
  哪几条狩技是 SP 型（数据在 `mArtsGaugeSPType`）[未确认]。
- 随从猫的支援行动也能给猎人附加 SP 状态，**时长分档**（wiki 2832 原文）：45 秒（多数）、60 秒（挑发之技）、
  75 秒（憤怒之技）、90 秒（部分随从猫专属技）。
- SP 状态期间的具体增益 wiki 未给出 [未确认]。

### 7. 随从猫技能（被动，passive）

与猎人技能是**两套独立系统**：随从猫技能不是点数阈值制，而是**每条技能带固定「記憶力」消耗（1~4 点）**的槽位制。

| 规则 | 内容 |
|---|---|
| 解锁 | 随从猫升级会解除技能键位锁（可装备），并**增加可装备的技能槽数** |
| 点数 | 每条技能标 ●~●●●● = 記憶力（memory）**1~4 点**；wiki 未给出预算上限与槽数曲线 [未确认] |
| 组别 | 技能分 A / B / C 三组，**同组之间可以互相「重新学习」**（A 组只能换 A 组的技能） |
| 技能类型 | 固有技（不可伝授）、準固有技（随机习得、可伝授/可重学；领袖猫没有）、共通技（全员自带，不可伝授/不可更换） |
| 伝授 | 随从猫道場可把已习得技能伝授给其它随从猫（配信猫的初始技也可伝授） |
| 雇主严选 | 雇用时可从「支援倾向 × 支援行动的组的構成 7 种」中挑选；被动技能则靠**同组重学**逐条替换 |

### 8. 支援行动（主动，active）

| 规则 | 内容 |
|---|---|
| 能量 | 每条支援行动有**能量消耗 1~5**（不是記憶力点数） |
| 解锁 | 用对应大型怪物狩猎来解锁（頁内「習得怪物」标注，如 冰牙龙 → SP 90 秒的技） |
| 8 点构成 | 组别 A/B/C 的点值 = **A:3 / B:2 / C:1**，合计恒为 **8**；7 种构成：`ABBC` / `ABCCC` / `ACCCCC` / `BBBB` / `BBBCC` / `BBCCCC` / `CCCCCCCC`（wiki 另注：领袖猫没有準固有技，故追加 1 点） |

### 9. 猫饭技能

#### 9.1 发动系统

猫饭由 **酱料（sauce，决定系统）+ 口味（flavor）** 两级构成，一次给 **3 个技能槽**：

| 槽 | 来源 |
|---|---|
| 技能 1 / 技能 2 | 由「酱料 × 口味」组合**固定**决定（见 2505 组合表） |
| 技能 3 | **每日抽奖**（`每日抽奖`）：每天随机的池；含酒食材的猫饭改用 `酒每日抽奖` 池 |

- **系统（4 类）**：攻击力 / 防御力 / 属性耐性 / 无加成；每个系统下挂 4~5 种酱料。
- **酱料（5 种）**：气势高昴 / 坚持到底 / 心跳不己 / 反复无常 / 新鲜现榨（同一酱料在不同系统下给不同技能）。
- **口味**：数值系统下为 6 种 —— 清淡 / 深厚 / 香醇 / 微甜 / 甘甜 / 辛辣；「无加成」系统改用 8 种村落口味
  （可可特风 / 西纳托风 / 浆波风 / 基可风 / 纳古利风 / 贝尔纳风 / 波克风 / 结云风）。
- 带 **[酒]** 的猫饭（食材含酒）其第 3 槽走 `酒每日抽奖` 池，其余走 `每日抽奖` 池。
- 部分组合的**技能 1/2 本身就是随机技**（如 招财猫的幸运 / 招财猫的恶运 成对出现），即该格也不固定。

### A. 技能点：**不落盘**，由装备实时推算

存档里**未见「技能点合计」或「已发动技能列表」字段**（技能比较/技能槽是 `cUIOSkillCompare` / `cUIOSkillSlot`
