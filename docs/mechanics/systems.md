## 核心机制

### 1. 调合（item merge）

#### 1.1 规则

| 项 | 值 | 出处 |
|---|---|---|
| 输入 | 恰好 2 个素材（固定顺序无关，表里素材 1/2 只是显示顺序） | 2503 |
| 输出 | 1 种结果道具 | 2503 |
| 个数 | `1` 绝大多数；`1-2`、`1-3`、`2-4` 少数；增殖类 `2-5` | 2503 |
| 成功率 | 离散值：`55 / 65 / 75 / 90 / 95 / 100` % | 2503 / combining.json |
| 配方总数 | **183**（wiki = JSON 一致） | 2503 / combining.json |
| 失败 | 素材消耗、无产出（wiki 未写例外）`[未确认]` | — |
| 加成 | 食事技能「猫之调和术【小】」+10%、「【大】」+20%（`2506`）；「猫之善使异臭球术」使异臭球配方必成功 | 2506 |
| 解锁 | 调合書①-⑤（1000/2000/5000/10000/15000z）；每本覆盖哪些配方、每本加多少成功率 wiki 未给 `[未确认]` | 2615 |

成功率分布（combining.json 实测）：`55%:8`、`65%:13`、`75%:33`、`90%:44`、`95%:30`、`100%:55`。
`amount_made_max` 实测最大 **4**，但 wiki 的增殖铁镐配方给 **5**（铁矿石/大地的结晶/上龙骨/王族金龟子）⇒ 见 §未确认。

## 与存档的关联

### A. 坐标约定（先读）

- `char_off` = 猎人槽文件内偏移（slot 文件 1,177,760 B；`.hnt` 是槽数据裸拷贝）。
- `obj+off` = 运行时成员#4 对象偏移。**两者不是同一坐标系**（例：`obj+0x42C` → `char_off 0x2C77`，差值随字段变化），必须查权威表 `quest/member4-file-layout.txt`。
- 存档无 CRC/hash，整块回写即可（`DEVELOP.md` 七条否定证据）。
- 位图寻址统一 LSB-first：`word = bit>>5`、`byte = word*4`、`mask = 1<<(bit&31)`。
