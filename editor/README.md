# MHGU 存档编辑器（实验便携包）

这是游戏外的浏览器工具，不是模拟器补丁，也不是 Forge 插件。**只修改浏览器内存，下载 `.edited` 副本，不覆盖原文件、不上传存档。** 未完成游戏端读档/保存验收，只使用存档副本。

## 启动

需要已安装 Node.js 18 或更新版本；不需要 `npm install`，没有第三方运行依赖。

1. 完整解压本包。不要把它放进游戏 Mod 目录，也不要只取出 `ui/index.html`。
2. 在解压目录打开终端，运行：

   ```text
   node serve.mjs
   ```

3. 打开终端显示的 `http://127.0.0.1:<端口>/ui/index.html`。端口自动选择；需要固定端口时可用 `node serve.mjs 8765`。
4. 用完在终端按 `Ctrl+C` 停止。服务仅监听 `127.0.0.1`，只提供列明的页面、模块和帮助文件，不提供存档读取、上传或写入接口。

**不要直接双击 HTML。** 页面使用 ES module 和 `fetch` 加载帮助，需要通过本机 HTTP 打开。从源码运行时，在 `editor/` 目录执行上述命令。

## 编辑存档副本

1. 退出游戏，备份整套存档目录；另外复制一份待编辑文件，不操作唯一原件。
2. 在页面选择 MHGU v1.4.0 的 `system` 或 `.hnt`。按文件大小识别：`system` 5,159,100 B、`.hnt` 1,177,760 B；同格式的 `system_backup` 可以作为单独输入，工具不自动同步两个文件。
3. `system` 选择角色槽位；`.hnt` 只有一个槽位。本工具不导入/合并 `.hnt` 到 `system`。
4. **按实际存档来源手动选择布局**：原版 `legacy`（2300槽/24预设），已采用V7格式的存档 `v7`（2992槽/14预设）。无法可靠自动识别，选错可能破坏预设；切换选项只是换读写解释，**不是布局转换**，也不会给游戏安装扩容功能。
5. 修改道具 ID/数量后按「写入」、Enter 或离开输入框，只更新内存。槽号从0开始，每页100槽。
6. 点「下载编辑后的文件」，获得 `<原文件名>.edited`。先保留原件，再在隔离测试存档中把导出副本改成原文件名，交给匹配布局的游戏环境验证。不要直接替换主档。
7. 若结果不正确，退出游戏并恢复整套原备份。不能靠卸载扩容补丁或改选 `legacy` 把V7存档转回原版。

## 页面实际提供的功能

| 区域 | 内容 | 边界 |
|---|---|---|
| 猎人头部摘要 | 名字、游戏时间、金钱、HR、性别 | 不是已验证的游戏内持久改值；现有规格称读档会丢弃头摘要、保存时重建，不应靠修改HR解锁任务 |
| 道具箱 | 显式布局下的每槽ID/数量，分页编辑 | 不提供原版/V7转换，不保证扩容补丁本身安全 |
| 无效槽检查 | 扫描道具箱/口袋的幽灵槽、零数量槽和越界槽 | 自动清除仅处理前两类，越界值需手动决定 |

本页面**没有**村庄点数、任务进度、装备或奖章编辑页。`core/progress.mjs` 是随包核心模块，不表示这些功能已经接入页面。字段帮助记录既有文档依据和限制，不代表本次重新验证了游戏机制。

## 文件

```text
serve.mjs          只读本机页面服务
ui/index.html      页面入口（通过终端打印的网址打开）
ui/app.mjs         界面逻辑
ui/style.css       样式
core/*.mjs         解析与内存写入模块
help/*.json        六份字段帮助数据
test/roundtrip.mjs 离线读改读控制，不写原始存档
```

## 可选开发者自检

```text
node test/roundtrip.mjs <隔离的存档样本目录>
```

脚本递归读取目录中大小符合格式的样本，在内存里检查列明字段/索引：同值写入的精确预期图像、改值读回、字段级字节/位掩码和可恢复值的回退。每个探针从原图像独立开始；名称合法清零/编码与脏任务同位规范化单独核对，不放行旁写。空目录、读取/容器错误、没有有效改值检查均非零退出；合法写入拒绝也必须保持字节不变。两种布局按假设分别检查，不是布局检测。该脚本不是玩家安装步骤，不覆盖所有writer，也不证明游戏读档、布局转换或字段语义正确。

本机入口的独立边界检查：`node --test test/serve.mjs`。它临时启动并关闭页面服务，只测静态资源/帮助可读和未知路径、写请求、跨站请求被拒；不读取你的存档。

核心写入边界回归：`node --test test/core-safety.mjs`。仅生成内存字节，检查重叠槽/容器前置区别名被拒、名字前导 `U+FEFF` 保留和预设名非法 UTF-16 在写前被拒；不读真实存档，也不证明游戏字段语义。`system` 的槽记录及其完整数据区必须互不重叠，槽数据不得进入规格规定的只读前置区（`0x0024..0x18CC9B`）；仍从表读取位置，不强制三个历史固定槽起点。

文件选择竞态回归：`node --test test/file-selection.mjs`。快速切换输入时仅最后一次选择生效，较早读取的成功或失败不能覆盖当前文件、视图或状态；测试使用合成内存文件与真实加载函数，不读真实存档。

姓名控件边界回归：`node --test test/name-input.mjs`。含CR/LF等单行控件无法无损显示的原名字，或包含非法UTF-8的原名字，会禁用名字写入并提示，保留原字节，其它字段仍可编辑；合法的U+FFFD不被误判。补充平面字符按码点和UTF-8字节限制验证，不因UTF-16单元数提前截断。仍不证明游戏接受这些名字。

## 扩容边界

编辑器与扩容实现是两件事。模拟器使用 `.pchtxt`，SUYU-GURecomp 的 PC 导出版使用 Forge PC 插件；本包不安装任何一种。当前V7还有已记录的辅助表容量/越界风险，V8和Forge扩容也没有因此成为稳定版。不要为了使用编辑器把主存档切到V7。
