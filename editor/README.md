# MHGU 存档编辑器（便携版）

单页应用，零依赖，双击 `ui/index.html` 即可用。所有解析与写回都在浏览器里完成，不上传任何东西。

## 用之前

1. **备份存档**。编辑器会直接改写你打开的那份文件。
2. 只支持 **MHGU v1.4.0** 的存档（`system` + `system_backup`）。
3. 如果你的存档打过**道具箱扩容补丁（V7）**，编辑器会按 V7 布局解析（2,992 槽 / 14 预设）；原版存档按 2,300 槽 / 24 预设解析。两者不能混用。

## 能改什么

| 页 | 内容 | 状态 |
|---|---|---|
| 进度 | HR、金钱、村庄点数 | 已实现，写回经过校验 |
| 道具箱 | 每格道具 id + 数量 | 已实现 |
| 装备 | 武器/防具记录 | 只读展示（写入规则见 `docs/editor-spec/`，部分条目被明令禁止写） |
| 奖章 | 只读 | **禁止写**（`docs/editor-spec/03` 的 I9，2026-11-04 判定 A/B 槽不是镜像对） |

## 文件

```
ui/index.html   入口页（双击打开）
ui/app.mjs      界面逻辑
ui/style.css    样式
core/*.mjs      解析与写回（container 容器、header 头、items 道具、progress 进度）
test/roundtrip.mjs  自检：读入→改→写回→再读，字段一致才通过
```

## 自检

```
node test/roundtrip.mjs <你的存档目录>
```

打印 `ROUNDTRIP OK` 表示读写一致。

## 已知限制

- 没有实机验证过（2026-11-04 的实机窗口只到标题画面）。
- 装备写入受 `docs/editor-spec/` 的禁写规则约束，编辑器不会越过这些规则。
- 存档结构级覆盖率约 87.8%，字段级约 14.9% —— 未覆盖的字段按原字节保留，不做猜测性写入。
